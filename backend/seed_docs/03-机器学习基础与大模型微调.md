# 机器学习基础与大模型微调

本讲义涵盖机器学习的基本范式，以及大语言模型的参数高效微调技术。

## 第一章 机器学习范式

机器学习主要分为监督学习、无监督学习与强化学习。监督学习使用带标签的数据训练模型，典型任务包括分类与回归。无监督学习从无标签数据中发现结构，典型任务包括聚类与降维。

## 第二章 过拟合与正则化

过拟合指模型在训练集上表现很好，但在测试集上泛化能力差，本质是模型记住了训练数据中的噪声。缓解过拟合的常用方法包括正则化（如 L1、L2）、Dropout、数据增强与早停。L2 正则化通过惩罚过大的参数来限制模型复杂度。

## 第三章 大模型微调技术

预训练大模型在海量语料上学习通用知识，微调则让模型适配特定下游任务。全参数微调更新模型的全部权重，效果好但显存与算力开销巨大。

参数高效微调（PEFT）只更新少量参数即可达到接近全参微调的效果。LoRA 是其中代表，它冻结原始权重，用两个低秩矩阵来近似参数更新的增量，从而大幅降低可训练参数量与显存占用。其它 PEFT 方法还包括 Adapter 与 Prompt Tuning。

## 第四章 指令微调与对齐

指令微调（Instruction Tuning）使用「指令-响应」格式的样本训练模型，使其更好地理解并遵循自然语言指令。在此基础上，基于人类反馈的强化学习（RLHF）进一步让模型输出与人类偏好对齐，是构建对话式大模型的关键步骤。
