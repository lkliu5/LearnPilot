# 技术文档界面截图脚本

为技术文档批量截取各功能界面图，输出到 `docs/screenshots/`（1440×900，带序号文件名，可重复运行覆盖）。

## 运行

```bash
# 前置：后端 + 前端已启动
cd backend && uvicorn app.main:app --port 8000
cd frontend && npm run dev            # 3001

# 截图（默认鼠尾草主题，13 张）
cd scripts/screenshots
node shot.mjs

# 可选：墨纸主题再截一套（文件名加 -ink 后缀）
node shot.mjs --theme=ink

# 可选：有头模式观察执行
node shot.mjs --headed
```

登录使用种子账号 `learner_001 / 123456`。依赖 `playwright`（本目录已 `npm i`，浏览器复用本机 ms-playwright 缓存的 chromium）。

## 需手动补拍的状态（脚本拍不到/不宜自动触发）

- **画像诊断·微测进行中**：02 拍的是诊断页入口态；若需「微测答题中」画面，手动走到微测第 2-3 题时截图。
- **工作流实时执行中**：11 若想拍「审核未过→重试」的红灯回环，需真实模式下触发低分重试（或用测试钩子），时机不定，建议手动。
- **内容安全拦截提示**：需构造违规输入才能触发降级提示条，不宜自动化，按需手动。
- **深浅主题对比**：跑一遍 `--theme=ink` 即得墨纸主题整套。

## 已知注意点

- 后端若在 F 盘重新挂载前启动过，SQLite 句柄会失效（登录报 5000）——重启 uvicorn 即可。
- 讲义/文档生成结果有全局缓存，二次运行秒出；删除 `backend/zhixue.db` 后首次运行会较慢。
