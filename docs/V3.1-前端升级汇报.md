# 智学中枢 · 前端 V3.1 视觉升级汇报

> **汇报日期**: 2026-06-01
> **范围**: 前端界面（React + TypeScript + Vite）视觉系统校准
> **目标**: 从「学生管理后台」气质升级为「AI Learning OS · 轻盈玻璃发光」，对齐原型图 `goal.png`，UI 还原度 ≥ 90%
> **方法**: 分阶段渐进式重构（P0–P5），每阶段实机截图 + 代码断言双重验证

---

## 一、背景与目标

本项目是「软件杯」赛题——**领域知识个性化资源生成与多智能体系统**的前端可视化系统。需求文档要求界面「轻盈、直观、高效」，原型图 `goal.png` 锚定的气质参考为 **Apple / Linear / Vercel / VisionOS**。

升级前，前端虽已实现四大页面框架（学情概览 / 画像诊断 / 学习路径 / Agent 工作流），但存在 **1 处方向性偏差 + 多处还原度欠缺 + 一批静默失效的样式隐患**。本次 V3.1 针对性校准。

---

## 二、升级前问题诊断

| # | 问题 | 影响 |
|---|------|------|
| 1 | **字体全站失效** | `index.html` 加载 Plus Jakarta Sans，CSS 却引用未加载的 `Inter`，且 Google Fonts CDN 在内网 `ERR_CONNECTION_CLOSED` → 全站回退系统字体，「distinctive typography」完全缺失 |
| 2 | **视觉方向漂移** | 代码演进成「神拟态（Neumorphism）」：灰底 `#eef2f7` + 双向软阴影，整体偏灰偏「黏土感」，与原型图「轻盈空气感」相悖 |
| 3 | **画像诊断页过薄** | 大白卡 + 灰色控件，视觉密度远低于其它页，全站气质不统一 |
| 4 | **Agent 大屏连线平淡** | 多智能体连接线是浅灰虚线，无发光、无流动，弱化了赛题「协同」重点 |
| 5 | **静默失效隐患** | 27 处硬编码神拟态灰阴影 + 11 处**未定义 CSS 令牌**（`--accent-*`×9、`--shadow-medium`×1 等），导致 RAG 节点配色、error 态、节点 hover 阴影等实际未生效却无人察觉 |

## 三、五阶段成果（P0–P4）

### P0 · 字体系统修复
- 放弃被墙的 Google Fonts CDN，改 **自托管 woff2**（`@fontsource` → `public/fonts/` + 自动生成 `fonts.css`，绝对路径规避 Vite 对相对路径不重写的坑）。
- 字族：拉丁标题 **Sora Variable** / 数据等宽 **JetBrains Mono** / 中文 **系统高质量黑体栈**（PingFang·鸿蒙·思源·雅黑，规避 75MB CJK webfont）。
- **效果**：`document.fonts.check` Sora ✅ JetBrains ✅，0 解码错误，全站离线可用。

### P1 · 玻璃发光视觉校准
- 背景 `#eef2f7`（灰）→ `#f8fbff/#eef4ff`（近白空气感）+ 三枚蓝/紫/绿动态光晕球（强度上调）。
- 阴影令牌：双向神拟态软阴影 → **单向玻璃投影 + 顶部高光**；hover 统一蓝色光晕。
- 清除全 `src/` **27 处硬编码神拟态灰阴影**（grep 确认 0 残留）。
- **效果**：卡片从「黏土灰边」变为干净玻璃浮起，背景轻盈、发光统一。

### P2 · 画像诊断（最弱页）补强【纯 CSS，零业务改动】
- 大白卡 → **玻璃卡 + 顶部蓝紫光晕条**；步骤条 → **渐变连接线**（绿→蓝→灰）+ 发光脉动节点。
- Chip 选中 `浅蓝底+深蓝字+内发光`；知识点卡选中蓝色光晕环；滑块蓝紫渐变轨道 + 发光滑钮。
- 结果页玻璃统计卡（数值渐变 mono）、绿色发光完成图标、渐变编号路径。
- **效果**：四步（basic/knowledge/generating/result）全部玻璃化，质感与全站统一。

### P3 · Agent 工作流发光网络
- 连接线 浅灰虚线 → **SVG 蓝紫渐变发光线**（`stroke:url(#flow-grad)` + 高斯发光滤镜）；运行态 `stroke-dashoffset` **流光粒子** 沿线流动。
- 节点激活 **ping 波纹**（1.8s 扩散）+ 蓝色脉动；节点玻璃化；RAG 紫色强调。
- **顺带修复 11 处未定义令牌**：`--accent-*`→`--purple-*`/红，`--shadow-medium`→`--shadow-glass-hover`。
- **效果**：多智能体协同的「数据流动」视觉成立，赛题重点凸显。

### P4 · 数据仪表化收尾
- 关键数值统一 **JetBrains Mono + tabular-nums**：仪表 `72.5` / 时钟 `01:01` / 气温 `22°C` / 统计 `65%·3·12`。
- 趋势卡 sparkline 加蓝色发光。
- **效果**：数字呈「AI 仪表盘」质感，与正文/中文清晰区分。

### P5 · 信息架构整理
- 将「设计系统 / 排版规范 / 组件示例」从 **学情概览** 抽离为**独立「设计系统」页面**（新增侧边栏导航项）。
- **效果**：业务页（学情概览）只承载业务内容，设计规范单独成页，便于答辩演示与开发参考，职责清晰。

## 四、关键技术亮点

1. **离线字体工程**：`scripts/build-fonts.mjs` 自动从 npm 包提取 woff2、重写路径、生成 `fonts.css`，一条命令可复现，无 CDN 依赖。
2. **令牌级风格切换**：90% 的玻璃化通过重定义 `globals.css` 设计令牌完成，组件零改动即继承新风格；仅对硬编码处做定点转换。
3. **SVG 流光网络**：用 `stroke-dashoffset` 动画实现「消息粒子沿连线流动」，比离散粒子更稳、更轻量，契合「轻·柔·慢·克制」动效纪律。
4. **隐患清零**：grep 驱动地清除全部硬编码灰阴影与未定义令牌，把「看起来能跑、实则失效」的样式债一次性还清。
