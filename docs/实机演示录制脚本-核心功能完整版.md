# 智学中枢实机演示录制脚本（核心功能完整版）

## 录制说明

- 录制地址：`http://localhost:3000/`
- 录制方式：浏览器真实点击、输入、滚动、等待接口返回，不使用静态截图拼接
- 目标分辨率：2560×1440
- 本版先输出无配音、无字幕的纯实机操作视频
- 下列旁白与画面操作严格一一对应，可直接用于后续 AI 配音
- 演示身份：第一次使用“智学中枢”、希望系统学习人工智能的初学者

---

## 第一段：认识 AI 学情管家

### 画面实操

1. 打开系统首页。
2. 停留在顶部学情概览，展示综合能力、知识点掌握、图谱覆盖和资源数量。
3. 缓慢向下滚动，依次展示“我对你的理解”“为你规划的路径”“学习监测”和 Agent 活动汇总。
4. 点击“查看完整画像”，然后返回学情管家。

### 旁白

大家好，接下来我会以一名人工智能初学者的视角，完整体验智学中枢。

进入系统后，我首先看到的不是课程列表，而是一位持续工作的 AI 学情管家。它把我的能力画像、学习路径、知识掌握度、已生成资源，以及多个专家智能体的工作结果集中展示在一个页面中。

顶部数据告诉我当前处于什么水平、掌握了多少核心知识，以及系统已经为我准备了多少学习资源。继续向下，可以看到系统对我的理解、为我安排的下一步、学习过程评估和主动建议。

这意味着我不需要自己在大量课程中反复筛选。系统会根据真实学习行为持续更新判断，并告诉我此刻最值得做什么。

## 第二段：用自然语言完成画像诊断

### 画面实操

1. 点击左侧“画像诊断”。
2. 展示三种诊断入口：做题式、一段话描述、直接跳过。
3. 点击“一段话描述”。
4. 在输入框中逐字输入：

   `我会一些 Python，也学过机器学习基础，但神经网络只理解基本概念，CNN 和 Transformer 还不熟悉。我希望系统学习人工智能，并能独立完成一个图像分类项目。`

5. 点击“解析为画像”。
6. 等待系统完成解析。
7. 展示能力、目标、偏好以及“自述·中置信”“待校准”等来源和可信度标签。

### 旁白

作为初学者，我可以选择自己最习惯的诊断方式。做题式诊断通过实际作答反推能力，可信度最高；如果想快速开始，也可以像我现在这样，直接用一段自然语言描述自己的基础和目标。

我告诉系统，自己会一些 Python，了解机器学习基础，但对神经网络、CNN 和 Transformer 还不熟悉，并希望最终完成一个图像分类项目。

系统不会把主观描述伪装成实测结果。自然语言推断会明确标记为“自述、中置信”；没有足够证据的学习偏好则标记为“待校准”。这种来源与置信度分离的画像机制，可以避免 AI 为了让画像看起来完整而随意编造。

后续的测验、学习进度、笔记和代码实践都会继续回流，逐步把画像从主观自述校准为真实行为画像。

## 第三段：生成并理解个性化学习路径

### 画面实操

1. 点击左侧“学习路径”。
2. 停留在路径概要，展示预计周期、知识点数量、总学时和当前进度。
3. 点击“卡片视图”，展示各知识点卡片。
4. 点击“时间线视图”，展示先修顺序。
5. 缓慢向下滚动，展示 CNN、Transformer、已掌握基础知识和后续知识点。
6. 停留在每个节点的“为什么这样安排”说明。

### 旁白

画像建立后，规划智能体会把我的能力、目标和知识点先修关系一起用于排序。

这里不仅给出学习顺序，还给出预计周期、总学时和每个知识点的预计投入。我可以在卡片视图和时间线视图之间切换，既能查看完整课程结构，也能看清前后依赖。

系统发现我的 CNN 和 Transformer 较弱，因此把它们放到前面集中攻克；已经通过测试的机器学习基础和神经网络基础则后置为快速复习。

每个节点都会解释为什么这样安排。这不是所有人共用的一张固定课表，而是一条可以被理解、可以随学情变化持续调整的个性化路径。

## 第四段：多模态资源与可信生成

### 画面实操

1. 点击左侧“学习资源”。
2. 点击顶部“可信度·点击查看机制”，展开多智能体交叉校验说明。
3. 展示六类资源入口：讲义、视频、思维导图、知识图解、代码和外部资源。
4. 点击“定制讲义”。
5. 等待讲义打开。
6. 依次切换“入门、初级、中级”等难度。
7. 点击讲义中的引用角标或来源入口，展开教材名称、原文片段和可信度。
8. 返回资源总览。

### 旁白

进入当前知识点以后，系统提供讲义、视频、思维导图、知识图解、代码实操和外部资源六种内容形态。它们不是一次性全部生成，而是根据我的需要按需调用。

讲义难度可以实时切换。初学阶段先使用更直观的类比和基础示例，掌握之后再逐步增加公式、代码与工程细节。

这里最重要的创新，是生成内容并非由一个大模型直接输出。系统先通过 RAG 检索可信资料，再由生成智能体编写内容，最后交给审核智能体逐条核对。未达到阈值的内容会被打回重写。

讲义中的引用角标可以展开到具体教材、具体原文片段和可信度。作为学习者，我不仅能看到答案，也能判断答案依据什么产生。

## 第五段：康奈尔笔记、费曼讲解与代码实操

### 画面实操

1. 进入“有序学习”。
2. 点击“康奈尔笔记”。
3. 在“线索”区域输入一个关键词，在“笔记”区域输入自己的理解，在“总结”区域输入一句总结。
4. 点击保存或完成。
5. 点击“费曼讲解”。
6. 输入：

   `神经网络可以理解为很多个简单计算单元连接在一起。每个神经元会把输入乘以权重，再加上偏置，最后通过激活函数决定输出。`

7. 点击提交讲解，等待 AI 指出遗漏与改进建议。
8. 点击“代码实操”。
9. 在代码编辑器中修改 `bias` 或 `weights`。
10. 点击“重新运行”，观察右侧输出变化。

### 旁白

系统的目标不是让我简单地看完内容，而是通过科学学习方法检验自己是否真正理解。

康奈尔笔记把线索、详细笔记和总结分开，引导我主动提炼内容，而不是机械复制讲义。

接下来，我用自己的话向 AI 解释神经网络。费曼智能体会判断核心概念是否准确，指出遗漏、混淆或表达不清的位置。只有能够真正讲明白，我才算跨过“看懂了”的错觉。

然后进入浏览器代码沙箱。我可以直接修改权重和偏置并重新运行，立即观察神经元输出如何变化。整个过程不需要配置本地开发环境，初学者也能把抽象概念转化为可验证的结果。

## 第六段：即时辅导与针对性补救

### 画面实操

1. 在学习资源页面点击右下角“即时辅导”。
2. 在输入框中逐字输入：

   `我还是不理解梯度下降为什么要沿着负梯度方向更新参数，可以用爬山的例子解释吗？`

3. 点击“识别问题→推荐针对性资源”。
4. 等待系统返回问题识别、苏格拉底式追问和针对性资源清单。
5. 选择一项针对性图解或讲义并生成。
6. 关闭即时辅导。
7. 打开定制讲义，选中一段正文。
8. 点击出现的“就这段问 AI”浮泡，展示选中即问。

### 旁白

如果我在学习中卡住，不需要离开当前页面重新描述上下文。点击右下角的即时辅导，就可以直接说明自己哪里没懂。

我现在询问，为什么梯度下降要沿着负梯度方向更新参数，并希望系统用爬山的例子解释。

即时辅导不会急着把标准答案塞给我，而是先识别我的具体问题，再通过苏格拉底式追问确认我卡在哪一步。如果仍然不理解，系统会结合当前画像、知识点和学习行为，生成针对性的图解、入门讲义、例题或视频。

阅读讲义时还可以直接选中文字，点击“就这段问 AI”。系统自动携带当前知识点和被选中的上下文，让问题始终留在真实学习现场。

这不是独立于课程的通用聊天窗口，而是学习过程中的实时反馈和精准补救。

## 第七段：基于个人文档的问答与资源生成

### 画面实操

1. 点击左侧“文档学习”。
2. 展示左侧已上传文档及解析状态。
3. 勾选文档作为当前问答范围。
4. 在中间输入框中逐字输入：

   `请总结这份文档的三个核心知识点，并分别标注对应的原文出处。`

5. 点击“提问”。
6. 等待回答完成，展示回答末尾的来源标注。
7. 在右侧点击“思维导图”或“练习题”。
8. 等待资源生成并打开结果。

### 旁白

除了平台规划的内容，我还可以上传自己的讲义、论文、Markdown 或 Word 文档。

左侧用于管理文档和选择当前范围，中间可以直接与文档对话。我要求系统总结三个核心知识点，并分别标注原文出处。

回答严格限定在被选中的文档中，无法从材料中确认的内容不会被补写。每个结论都能回到原文核对。

右侧还能基于同一批文档生成讲义、视频、图解、思维导图、练习题和记忆闪卡。这样，个人资料也可以被转化为完整的学习流程，而不再只是存放在文件夹里的静态材料。

资源可以再次打开查看，也可以下载保存。这让每一次与 AI 的学习交互都形成可复用的个人资产，而不是对话结束后就消失。

## 第九段：真实多智能体工作流

### 画面实操

1. 点击左侧“Agent 工作流”。
2. 在知识点下拉框中选择“CNN 架构”。
3. 在难度下拉框中选择“初级”。
4. 点击“启动工作流”。
5. 等待并展示诊断 Agent、生成 Agent、审核 Agent 的状态变化和消息日志。
6. 重点停留在审核评分、打回重写、重试轮次和最终完成状态。
7. 向下滚动，展示独立运行的学习过程评估 Agent。

### 旁白

在工作流大屏中，我可以看到系统背后的多智能体协作过程。

我选择 CNN 架构和初级难度，然后启动工作流。诊断智能体先读取画像和当前学情；生成智能体结合 RAG 资料编写内容；审核智能体再检查事实、术语、难度和引用。

如果审核评分没有达到阈值，内容会被真实地打回生成节点重新编写，而不是直接交付给学习者。消息日志记录了每个节点的输入、输出和状态变化。

下方的学习过程评估智能体则跨会话持续运行，累计测验、进度、笔记和实操行为，再反向更新画像、路径和学习建议。

这套由 LangGraph 编排的诊断、检索、生成、审核和评估闭环，是智学中枢区别于单次大模型问答的核心。

## 第十段：知识图谱与模型管理

### 画面实操

1. 点击左侧“知识图谱”。
2. 展示 78 个知识点、7 个板块和当前覆盖率。
3. 点击“深度学习核心”板块。
4. 展示入门、进阶、前沿层级以及板块内先修关系。
5. 返回全部板块。
6. 点击左侧“模型管理”。
7. 展示默认模型、内置模型与自建模型。
8. 停留在脱敏 API Key、测试、切换和自动回落说明。

### 旁白

最后，我可以从单个知识点回到完整的人工智能知识图谱。

这里包含七个板块、七十八个知识点。板块覆盖率来自我的真实学习状态，节点之间的连线展示先修依赖。我可以进入深度学习核心板块，查看从入门到进阶再到前沿的完整脉络，明确自己目前位于体系中的什么位置。

模型管理页面支持默认模型、内置模型和用户自建模型。API Key 只以脱敏形式显示，模型可以测试和切换；当外部模型不可用时，系统还能自动回落到默认模型或离线 Mock，保证学习链路不中断。

从读懂学习者、规划个性化路径，到可信生成、科学学习、即时辅导、文档问答和持续评估，智学中枢把原本分散的功能连接成了一个完整闭环。

以上就是智学中枢的实机演示。

## 后期配音建议

- 声线：轻柔、清晰、偏年轻的女性声音
- 语速：每分钟 220～250 个汉字
- 停顿：点击后停顿约 0.5 秒，等待生成时可保留 1～2 秒环境画面
- 口播原则：先说明用户遇到的问题，再解释当前操作，最后点出项目创新价值
- 字幕建议：后续以操作段落为单位切分，每行不超过 22 个汉字
