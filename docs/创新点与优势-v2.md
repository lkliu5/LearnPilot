## 维度一 · 教育理念与学习方法论创新（**最大差异化，多数团队没有**）

> 这是本项目最独特的一层：不只"生成内容"，而是把公认有效的学习方法论工程化、AI 化落地，让学习"科学地发生"。

**1. 苏格拉底式启发问答（不给答案，引导思考）**
- 不直接抛答案，而是层层追问引导学习者自己想通——符合建构主义学习理论与最近发展区（ZPD）；
- **每个知识点有专属的引导脚本**：6 个核心点手工精修引导链，其余按知识点参数化生成——学 CNN 时问的是"全连接处理大图有什么麻烦"，学 Transformer 时问的是"RNN 串行的痛点"，**不会串味**。

**2. 费曼讲解（以教代学，精准暴露盲区）**
- 学习者用自己的话讲出来，AI **按该知识点的关键概念检查表**逐项核对；
- 实例：学 CNN 时讲了卷积核但漏了池化 → AI 反馈"你讲清了卷积核与局部感受野，但遗漏了池化层"+ 定向回看资源 + 追问；
- **不是泛泛打分，是精准指出你哪里没讲清**。

**3. 康奈尔笔记法（结构化复述）**
- 三栏式（要点/复述/总结），把纸笔时代的经典方法数字化嵌入学习闭环。

**4. 掌握式学习（Mastery Learning）**
- **≥70 分才进阶**，未达标 → 错题强化 → 重测。践行卡罗尔-布鲁姆的掌握式学习理念：**达标才推进，不留夹生饭**。

**5. 间隔重复与主动回忆**
- 记忆闪卡（正反翻卡）+ 错题强化卡，基于艾宾浩斯遗忘曲线与测试增强效应。

**6. 科学的学习流程编排**
- 有序学习按 **输入（视频/讲义/图解）→ 康奈尔笔记 → 费曼讲解 → 代码实操 → 阶段测试** 编排；
- 覆盖"多模态输入 + 主动输出 + 动手实践 + 测评反馈"的完整认知链条。

**理论支撑**：建构主义（皮亚杰）/ 最近发展区（维果茨基）/ 掌握式学习（卡罗尔、布鲁姆）/ 两西格玛问题（布鲁姆 1984）/ 测试增强效应（Roediger）/ 间隔重复（Cepeda）

## 维度二 · 个性化创新（**真因材施教，不是换皮**）

**1. 行为实测画像（做题反推，防自我报告失真）**
- **不是"你觉得自己几分"，而是"做题结果反推真实能力"**——你以为会了但题错了，系统知道；
- 对话 + 诊断微测 + 偏好选择三段式；能力实测打分、偏好归类型（不打分）、主观信息描述，三类分开；
- 三种入口（做题式 / 一段话自述 / 零基础跳过），并**标注画像来源与置信度**（实测·高置信 / 自述·中置信 / 未测·默认）——**诚实透明，不假装我们什么都知道**。

**2. 双驱动路径规划（CPDP 算法）**
- **能力画像 → 决定"学什么、什么顺序"**（薄弱前置、已掌握后置，遵循知识图谱先修依赖的拓扑序）；
- **偏好画像 → 决定"每步用什么形式"**（图像型→图解、案例型→例题、概览型→思维导图）；
- **学习时间线**：每点预计时长、路径周期/总时长/进度、节奏建议；
- 画像变 → 路径实时重算。**两个不同学生，路径的节点、顺序、推荐形式全不同。**

**3. 学情管家统筹全局**
- 推测需求（画像）→ 为你规划（路径 + 时间线）→ 监测进展（掌握度 + 各 Agent 活动）→ 主动建议；
- 形成连贯的"AI 统筹学习"闭环，而非一堆孤立功能。

## 维度三 · 技术架构创新（**多智能体有真实深度**）

**1. 真实多智能体协同（不是几个提示词轮流跑）**
- 基于 **LangGraph** 的工作流：**诊断 → 检索 → 生成 → 审核 → 决策**，含**重试 / 降级回环**；
- **关键：审核 Agent（Critic）有否决权**——生成内容逐句核查，不合格**打回重试**，根本到不了用户面前；
- 这是我们和"看起来像多智能体"的**本质区别**：我们的 Agent 之间有真实的**约束关系与决策权**。

**2. Agent 五层架构（认知 / 规划 / 执行 / 记忆 / 监督）**
- 认知层=理解真实需求；规划层=约束下最优路径；执行层=事实核查动态调整；记忆层=画像/掌握度持久化；监督层=防幻觉 + 内容安全；
- **平台自身即多智能体最佳实践**——学习者学 Agent 知识点时，可印证"本平台就是这么实现的"，**学以致用的闭环**。

**3. 完整 RAG 管线（每一环都真实存在）**
- Chunker → bge-small-zh 嵌入 → Chroma 向量库 → **RRF 混合检索（向量 0.7 + BM25 0.3, k=60）** → bge-reranker 重排 → **逐句接地**；
- 不是"调个向量库"，是完整工程管线。

**4. 多模型可切换 + 用户自配（工程灵活性 / 国产化）**
- 支持多模型切换、接入国产魔搭社区、用户界面自配 API Key（加密存储 / 脱敏 / 隔离）；
- **不绑定单一厂商**，为跨平台产品化打底。

**5. 真讲解视频服务端渲染**
- **Remotion 服务端渲染真 mp4**（画面 + 字幕 + 语音一体），非"幻灯片 + 外挂音频"；
- 5 个核心知识点各配精修分镜脚本，**每个知识点讲的都是它自己**（cnn 讲卷积池化、transformer 讲自注意力）。

## 维度四 · 可信 AI（**教育场景的生死线**）

**1. 逐句接地防幻觉（GCG 算法）**
- 每句生成内容与检索证据做语义比对，**相似度 ≥ 阈值判定为"已接地"**，未接地 → 审核 Agent 打回重试；
- **阈值 0.6 是科学标定的**：bge 实测中位数 0.73，若用 0.75 会误判 62% 的已接地句子——**我们用真实数据标定，不是拍脑袋**；
- **实测幻觉率 < 5%**。

**2. 全链路可溯源**
- 学生看到的每一句话，都能点开看出处（论文级引用标注）；
- 低置信内容标注、无材料不臆造。
- **我们敢让 AI 被检查。**

**3. 消融实验证明"防幻觉不是摆设"**

| 配置 | 幻觉率 |
|---|---|
| 完整系统 | 0.0589 |
| **去掉 RAG** | **0.1549（恶化 2.6 倍）** |
| 去掉重试 | 0.0682 |

> 去掉 RAG 幻觉率恶化 2.6 倍——**这是我们的防幻觉真的在起作用的硬证据**。

**4. 内容安全能区分"讨论"与"指导"**
- 精细的教育性语境豁免：讲 AI 安全时引用"模型应拒绝制造危险品"**不误拦**，真正的危险配方步骤**才拦**；
- 在"不误伤正经教育内容"和"拦住真违规"之间取得平衡——**这是很多粗糙的内容过滤做不到的精细度**。

## 维度五 · 工程鲁棒性与质量治理（**v2 新增 · 这是成熟度的硬证据**）

> 一个 Demo 和一个可交付系统的区别，就在这一层。

**1. 零外部依赖的关键功能（离线可用）**
- **代码实操：本地 srcdoc 渲染**，不依赖任何第三方沙箱服务——**断网也能跑**；
- 我们**主动移除了对 CodeSandbox 的依赖**，因为第三方服务会静默变更、且现场网络不可控；
- **资源推荐：联网失败可降级到精选种子库**，不让用户干等或看到报错。

**2. 系统性的质量治理（我们做了什么，比结果更能说明专业度）**
- 主动排查并修复了 **6 处"演示件未跟随参数化"的隐患**（导学开场白、费曼 chips、费曼底层评估器、讲解视频分镜、代码实操、错题强化）；
- 这类 bug 极隐蔽——默认知识点下一切正常，换个知识点才暴露。**我们不等它在答辩现场炸，而是主动全局排查、逐个修复、逐个知识点实测验证**；
- **结果：任意知识点（含 78 个体系点中的任何一个）打开任意资源形态，内容都跟随该知识点，不串味。**

**3. 诚实的能力边界（不假装万能）**
- 6 个核心知识点：**手工精修**的引导脚本、分镜、代码 demo；
- 其余 72 个体系点：**参数化通用模板 + RAG 接地 + 审核 Agent 把关**，且**在界面上明示"通用讲解模板"**；
- **我们不假装每个点都是定制的**——诚实的产品比吹牛的产品更值得信任，这也是可信 AI 的一部分。

**4. 完整的工程质量**
- **290 项自动化测试全部通过**；
- 前后端分离、接口契约清晰、可独立部署；
- 产物落库（读产物不重复烧 API）、成本可控（单份 ¥0.0197）；
- 完整技术文档（架构 / 接口 / 测试 / 部署 / AI 辅助说明）。

# 🛡️ 答辩防御（必被问的 5 个问题）

**1. "你的多智能体是真协同还是几个提示词？"**
→ 讲**审核 Agent 的否决权**、LangGraph 的状态流转、重试/降级回环。**关键词：Agent 之间有真实的约束关系与决策权。**

**2. "消融实验里去掉 critic，幻觉率反而降了（0.0490 < 0.0589），怎么解释？"**（**最刁钻**）
→ **诚实回答**：critic 会打回重试，重试后的内容可能引入新表述；两组批次有差异。**关键：critic 的价值不只是降幻觉率，更是拦截不合格内容（完整性、安全性）**。别硬圆，坦诚 + 解释设计意图。

**3. "78 个知识点的内容质量怎么保证？非核心点是 AI 生成的吗？"**
→ **诚实**：6 核心点手工精修，其余参数化模板 + RAG 接地 + 审核把关，**且界面上明示"通用模板"**。**我们不假装全定制——这本身就是可信 AI 的态度。**

**4. "阈值 0.6 怎么定的？"**
→ 讲标定过程：bge 实测中位数 0.73，0.75 会误判 62% 已接地句子，最终标定 0.6。**科学标定，不是拍脑袋。**

**5. "和 NotebookLM 有什么区别？"**
→ ①我们有**画像和路径**（它没有学习闭环）②我们**懂教育方法论** ③我们**多智能体 + 可信保障**。**NotebookLM 是工具，我们是学习系统。**
