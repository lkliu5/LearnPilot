# 角色

## 任务 1（问题 1）：阶段测试改为"一轮一测 · 终点 gate"
**现状（先查并报告）**：阶段测试当前是怎么放置和记完成态的？为什么"做完测试后翻看下一份资源会显示测试已完成"（完成态是否跨资源 tab 串了）？

**修复目标**：
- 一个知识点的有序学习流里，**阶段测试是唯一的终点 gate**：完成学习内容步骤（视频/讲义/图解/实操/费曼）后，**在末尾呈现/解锁一份阶段测试**，不再在每个资源页都挂"分阶测试"栏、也不可在学习内容没走完时独立完成。
- 测试完成态**绑定到该知识点的测试本身**，不跨资源页串显示；不再出现"看视频时发现测试已完成"的误导。
- **通过测试 = 已掌握 = 进度推进**（复用既有 quiz→Mastery 逻辑，不新增掌握度路径）。

## 任务 2（问题 2）：画像统一 + 重做覆盖
**现状（先查并报告）**：对话诊断 / 简历分析 / 手动填写 三条路径各自写入什么画像结构？为什么产出的雷达维度不同？

**修复目标**：
- 三条路径统一写入**同一份权威画像（canonical StudentPortrait，同一套维度）**；简历/手动路径把输入**映射到相同维度**，不再另造一套雷达。
- **重做诊断 = 覆盖更新**该权威画像，并刷新学情概览；不产生分叉的第二份结果。
- 学情概览雷达 = 该权威画像维度，**三条路径完全一致**。
- 注意：异质画像维度（知识基础/认知风格/…）与"知识掌握雷达"是两类不同图、可并存；但"诊断产出的画像"只能有一份、各路径一致。

## 任务 3（问题 4）：工作流学情诊断接真实用户数据
**现状（先查并报告）**：工作流诊断节点是否读了**当前用户**真实的 StudentPortrait + Mastery？还是用通用 prompt 产出"人人一样"的诊断（如固定那句"大模型应用工程师…注意力机制/Transformer/微调"）？

**修复目标**：
- 诊断节点读**当前用户真实画像 + 掌握度（真实薄弱点）**，生成**因人而异**的学情诊断；不同用户 / 不同掌握度 → 诊断内容不同，不再是写死/通用模板。
- Mock 模式仍可跑（mock 下用该用户的占位画像派生，而非全局同一句）。

# 约束

- 保留 Mock 兜底；不动其它无关模块。

# 验证（逐项实测并贴结果）
1. 阶段测试：学习内容没走完时测试不可完成；走完后末尾出现一份测试；通过→已掌握+进度推进；切到别的资源页**不再显示"测试已完成"**误导。
2. 画像：用对话、简历、手动三条路径各做一次，产出的画像维度**一致**；重做诊断**覆盖**旧结果并刷新学情概览。
3. 工作流：用两个掌握度不同的用户各跑一次，学情诊断内容**不同**、对应各自真实薄弱点（贴两段对比）。
4. 全量测试通过、既有接口回归未变；tsc 干净。
