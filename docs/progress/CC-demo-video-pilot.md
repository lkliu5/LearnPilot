# 角色
资深前端/自动化工程师。本会话产出"演示飞行脚本"+演示数据预热，辅助团队录制 ≤7 分钟演示视频。**不改业务代码**。

# 前置
- 真实模式跑通：后端 `uvicorn app.main:app --reload --port 8000`（deepseek 真实 Key）+ 前端 dev server。
- 准备一个**演示账号**，状态干净但有内容（画像已诊断、有少量学习/做题记录，便于展示评估/路径）。
- **预热缓存**：把要演示的知识点的讲义/视频脚本/工作流先各跑一遍命中缓存，现场不卡。

# 任务 1：演示飞行脚本（Playwright）
按 `演示视频脚本与PPT大纲.md` 的 7 分钟顺序，写一个 Playwright 脚本自动操作运行中的应用，**节奏放慢到人能看清**（每步之间留停顿）：
1. 登录演示账号；
2. **对话式画像**：逐条输入真实对话、等 SSE 流式追问渲染、右侧 6 维逐格填充 → 确认画像弹窗；
3. **多智能体工作流**：触发工作流大屏，等节点逐个真实点亮；**尽量演示一次审核不通过→重试→降级的回环**（最有说服力）；完成弹窗 → 跳转看生成产物；
4. **个性化学习路径**：展示路径、薄弱优先；
5. **有序学习闭环**：康奈尔三栏记笔记 → 费曼讲解（提交不完整讲解、看 AI 指出缺口）→ 末尾阶段测试通关；
6. **资源卡片中枢**：点开讲义卡（过场动画）、资源推荐（联网搜索结果）；
7. **加分速览**：智能辅导"我没懂"→资源清单、学习评估卡。
- 全程操作**有意放慢 + 适当停顿**，总时长可控（便于剪辑）；关键处可在控制台打印"〔阶段X〕"方便对齐旁白。
- **可选**：Playwright 开 `recordVideo` 直接录一条走查 .webm 作底稿。

# 任务 2：旁白时序表
基于上面的操作顺序，输出一份**旁白时序表**（每个阶段：操作 + 对应旁白 + 大致时长），和 7 分钟脚本对齐，方便后期配音卡点。

# 输出
- Playwright 飞行脚本文件（可重复运行）+ 运行说明；
- （可选）录制的走查 .webm；
- 旁白时序表。
完成即停。

## 提示（给你人看）
- **推荐用法**：让脚本当"自动飞行员"，你这边开 **OBS 录屏**跟着它跑——这样能拿到高清画面、还能后期加光标特写/放大/字幕。Playwright 自带的 `recordVideo` 画质一般、固定分辨率，当备用底稿可以，正式录还是 OBS 更好。
- **真实模式有延迟是正常的**，预热缓存能缓解；工作流那段的真实重试/降级**别剪掉**——那是"真 Agent 协同"最硬的证据。
- 幻觉率挑能跑出**小非零值**（如 0.021）的主题演示，比清一色 0.0 更可信。
- 录完你来做配音 + 剪辑 + 卡 7 分钟；旁白照"旁白时序表"念就行。
