## 边界与兼容性

- Mock 继续调用统一文档要点句抽取器，按原文顺序、去重并按 count 限制卡片数量。
- 卡片正面继续用原文前 14 字生成主题问题，背面继续逐字使用文档原文要点。
- 无可用正文时继续返回单张“不臆造内容”的格式检查提示卡。
- 真实输出继续支持普通 JSON 与 Markdown JSON 围栏，过滤空 front/back 并按 count 截断。
- 无任何有效卡片时继续抛出原有 `LLMGenerationError`，由 Provider 编排回落 Mock。
- `LLMClient._mock_flashcards` 的签名与调用方式保持不变；DeepSeek Prompt 和降级标记逻辑保持原位。
- `llm.py` 从 E13 后的 1864 行降至 1844 行。
