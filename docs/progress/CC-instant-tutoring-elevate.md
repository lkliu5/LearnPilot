# 先查并报告
现在「🆘我没懂」入口在哪个组件、什么位置、怎么触发？（应在 SocraticTutor / TutorResourcePanel 一带，且位置不显眼。）

# 改造
1. **改名升格**：把"🆘我没懂"统一改为「**即时辅导**」，去掉"求助/我不行"的被动感，呈现为主动的核心能力。
2. **显眼常驻入口**：在学习内容区（讲义/视频阅读旁）放一个**醒目的常驻「即时辅导」入口**——"学到卡住随手就能问"，而不是藏在面板最下方。视觉上给到学习区辅助工具的显著权重（套现有设计令牌），做成**固定的辅助工具条 / 侧边按钮**。
3. **不与"去通关"主按钮抢焦点**：去通关仍是全页主操作；即时辅导是显眼但次一级的常驻辅助入口，两者视觉层级分明。
4. **保留现有交互链路**：点击 → 描述问题 / 识别问题点 → 针对性资源清单 → 勾选按需生成（这条已实现的链路不变，仅入口更显眼、命名更主动）。
5. **可选增强（成本可控才做）**：支持"针对当前讲义内容提问"——讲义阅读时能就当前知识点直接发起即时辅导，让"针对性"更具体。若改动成本高则跳过，先把入口升格做扎实。

# 约束
复用现有 tutor suggest/generate 接口与 TutorResourcePanel / 逐项生成组件；不改后端；深浅主题正常；不动其它资源类型。
