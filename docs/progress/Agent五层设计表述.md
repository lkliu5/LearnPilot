# 智学中枢 · Agent 设计哲学五层表述（答辩/PPT 用）

> 用途：用"认知/规划/执行/记忆/监督"五层框架，把已实现的功能重新表述为"为什么这么设计"。**不改任何代码**，纯叙事升格。答辩被问"你的 Agent 是怎么设计的"时，按这五层讲，比罗列功能高一个层次。
> 注意：本系统是**教育辅助 Agent**，核心价值是"准确、因材施教、可信"，不是企业级"自主决策担责"。下文把五层语言**收敛到教育场景**，不要照搬"自主决策/算账/熔断"那套商业叙事，否则场景错配反而减分。

---

## 一句话立意

智学中枢不是"给学生一堆课程让他自己学"，而是一个**目标驱动的学习决策系统**：学生只需说出目标与困惑，系统自己去**拆解需求 → 规划路径 → 生成资源 → 核查可信 → 评估反馈 → 主动辅导**。它设计的不是界面，是"一个可信助教的判断力"。

---

## 第一层 · 认知层：理解"学习者真正要什么"，而非执行指令

**原则**：用户的指令不等于真实目标，先做目标拆解。

**智学中枢的实现**：我们摒弃了填表式画像，用**对话式画像诊断 Agent**——学生说"我想学神经网络"，系统不直接丢一篇讲义，而是在对话中还原他的**知识基础、认知风格、易错点、学习目标、先验经验、学习节奏** 6 个异质维度，把"模糊的学习诉求"拆解成"可被规划的真实学情"。诊断节点读取该学生**真实画像 + 掌握度**，因人而异。

**答辩话术**：这一步决定了系统是在"派发资源"还是在"解决这个学生的问题"——前者是内容库，后者才是个性化 Agent。

---

## 第二层 · 规划层：在"学情约束"下找最优学习顺序，而非罗列知识点

**原则**：规划不是真空找路径，而是在约束下找最优解。

**智学中枢的实现**：**学习路径规划 Agent（planner）**按真实画像 + 掌握度对知识点打分排序——**薄弱点优先、已掌握的自动后置**，不同画像得到不同路径。"值不值"在教育场景对应"学习性价比"：先补最影响目标、最薄弱的环节，而不是从头平铺。

**答辩话术**：规划的本质是取舍。不看学情、人人一套大纲的，是课程表；按薄弱点排序、千人千路径的，才是规划 Agent。

---

## 第三层 · 执行层：内容不是"生成"出来的，是"核查"过的

**原则**：执行层的核心不是会调多少工具，而是敢不敢基于事实动态调整。

**智学中枢的实现**：这是最硬的一层。资源生成走**真实 LangGraph 五节点工作流**（诊断 → 检索 → 生成 → 审核 → 决策）：生成 Agent 产出讲义后，**审核 Agent 基于 RAG 知识库逐句做接地校验、真算幻觉率**，超阈值就**打回重新生成**（真实回环重试）；RAG 用混合检索 + rerank**优先采信高置信来源**。这正是"基于可信事实动态调整原计划"。

**答辩话术**：我们的执行层关注的第一个问题不是"怎么把内容生成出来"，而是"生成的内容可不可信"——审核不过就重做，这是 Agent 执行层真正的能力。

---

## 第四层 · 记忆层：越用越懂这个学生，而非每次从零开始

**原则**：短期记上下文、长期沉淀经验、情景调取相似处置。

**智学中枢的实现**：
- **短期**：当前学习会话 / 导学对话的上下文连贯；
- **长期**：掌握度状态机 + 学习旅程 + 学生画像**持久化**，画像随学随新——沉淀这个学生的能力轨迹；
- **情景**：基于 **QuizAttempt 行为埋点的学习评估 Agent**，从历史做题/学习行为做多维评估；**主动察觉卡顿**机制识别"同一知识点反复看、测验出错"等困境信号、主动调取辅导——这就是"遇到相似困境主动响应"的教育版。

**答辩话术**：没有记忆的系统每个学生都当新手教；有记忆的系统，越用越懂他薄弱在哪、卡在哪。

---

## 第五层 · 监督层：事前护栏，而非事后追责

**原则**：上线翻车多半不是推理不行，是行动前没有安全阀。

**智学中枢的实现**（教育场景的三道护栏）：
- **合规校验** → **内容安全过滤**：所有生成内容经集中钝化点统一检测敏感/违规，且不误伤"网络攻击/战争史"等学术语境；
- **不确定性预警** → **防幻觉机制**：推断维度标**低置信**、来源**可溯源**、无材料**不臆造**、幻觉率逐句真算；
- **紧急熔断** → **审核降级终态**：工作流三次审核仍不过，不硬出可能错的内容，而是**降级并如实告知"审核未完全通过"**。

**答辩话术**：对教育产品，最该有的不是"跑得快"，是"不误导学生"。敢说"这部分我不太确定"的 Agent，比什么都敢答的 Agent 更值得信任。

---

## 收尾：本质区别（可用作 PPT 创新页结语）

传统学习平台帮你"把课程搬到线上"，给你一堆资源，你自己找、自己学。智学中枢帮你"把学习这件事的决策扛下来"——你说出目标和困惑，它拆解、规划、生成、核查、评估、主动接住你。

我们设计的不是"更好看的学习界面"，而是一个**可信助教的判断力**：什么先学、什么内容可信、什么时候该说"我不确定"、什么时候该主动问你"是不是卡住了"。

---

## ⚠️ 使用提醒（避免减分）

- **用五层语言"解释你已做的"，不要去"补做"五层里你没有的东西**——离截止不远，任何为套框架而做的重构都是风险。
- **监督层就讲"防幻觉/内容安全/不误导"**，别谈商业"熔断/预算红线"——那不是你的场景。
- **强调"人始终主导"**：学生确认画像、勾选生成、决定学什么——你的 Agent 是"可信辅助"，不是"自主担责"，这个边界讲清楚反而显成熟。
