# CC 指令 · S11 — 学习流程重构（费曼 + 康奈尔学习法）

> 对应第二轮测试问题 5（按钮分工）+ 6（学习内在逻辑 + 测试通关 gate）。
> 涉及前后端，按契约 → 后端 → 前端三步拆，每步一个独立 CC 会话。
> 全局纪律照旧：已联调接口签名禁改、统一信封、Mock/真实双模式、复用优先、完成即停、实测 0 报错、新增接口追加不重排。

## 设计总览（三步共享）
一个知识点的学习页 = **学习内容区（有序）** + **阶段测试区（独立 gate）**：
1. 输入 + 康奈尔记笔记（视频/讲义/图解 + 主笔记/线索栏/总结三栏面板，线索问题系统生成）
2. 复述 + 总结（用线索问题自测 + 总结区写自己的话）
3. 费曼讲解（向系统讲清概念，系统找知识缺口、引导补缺；复用苏格拉底 Agent）
4. 阶段测试通关 = 已掌握 = 进度推进
按钮：「开始学习」=进有序流接着学；「查看资源」=自由浏览 8-tab。

## 提示
- 先跑 S11a 定契约（尤其确认"测试通过如何驱动 Mastery 推进"的对接方式），再 S11b/S11c。
