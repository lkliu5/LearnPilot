## 会话一 · 修复批（问题 2 / 3 / 4）

═══════════════════════════════════════════════════════════════
# 角色
资深前端/全栈工程师。项目已联调，禁改既有接口签名。本会话修 2 个 bug。

## 任务 1（问题 2 + 3）：导航后内容刷不出来，需整页刷新才恢复
**现象**：① 学习资源点「查看生成过程」跳到 Agent 工作流过程界面，有时刷不出来；② 点「学情概况」同样；③ 从「学习主线」切到「总览与工具」时，内容有时刷不出来——只有整页刷新才恢复（且回到初始状态）。
**先查并报告**：怀疑路由切换时组件没重新拉数据/没重新挂载、WS 订阅断了没重连、某个全局 loading/error 态卡死、或异步竞态。定位这几个视图共同的渲染失败根因。
**修复**：让这些视图在**路由进入时可靠地重新加载并渲染**——正确的 useEffect 依赖、进入即拉数据 / 重连 WS、补 loading/error 态兜底，不依赖一次性挂载；彻底消除"需整页刷新才恢复"。
**验证**：在这几个视图间快速来回切换多次，内容稳定渲染、无需整页刷新、不回退初始态。

## 任务 2（问题 4）：工作流三次审核都不过时，不出成果弹窗
**现象**：Agent 工作流若三次内容审核都没通过，不会弹窗显示生成了什么内容模块。
**先查并报告**：score<0.8 重试三次都失败后，当前走没走降级终态？为什么没触发完成弹窗？
**修复**：即使三次校验都未通过、走降级终态，也要**触发完成弹窗、展示降级生成的内容**，并明确标注"审核未完全通过 / 已降级生成"之类提示；不要让用户卡在没有任何终态反馈。
**验证**：构造（或调阈值模拟）一个三次都不过的场景，确认终态出弹窗 + 展示降级内容 + 有降级提示。

# 输出
2 项现状说明 + 改动文件清单 + 验证结果 + 红线自检。完成即停。

## 会话二 · 功能批（问题 1 / 5 / 6）

═══════════════════════════════════════════════════════════════
# 角色
资深前端/全栈工程师。项目已联调，禁改既有接口签名。本会话调整生成体验。

## 任务 1（问题 1）：学习过程评估纳入 Agent 大屏
**现状（先查）**：Agent 大屏当前展示哪些 agent / 节点？学习评估 Agent（批3-A）有没有在大屏体现？
**改**：在 Agent 大屏**体现"学习过程评估 Agent"**——作为多智能体系统的参与方展示（agent 卡 / 面板 + 它的多维评估输出）。
- 注意：评估是**跨会话的累积评估**、不是单次生成流程里的节点，所以更适合作为大屏里的**一个独立 agent 面板/区块**呈现其最新评估结果，而非强行塞进 LangGraph 运行路径。
**验证**：大屏能看到学习评估 Agent 及其评估输出，体现系统含评估能力。

## 任务 2（问题 5）：选择性生成 + 可见进度（不再一次性等全部）
**现状（先查）**：现在资源生成是不是一次性把多种内容全生成完才显示？
**改**：让用户**勾选要生成的内容类型**（讲义/视频/图解/思维导图/代码等），按选择**逐项生成**，每项有**实时进度/状态**，生成完一项就展示一项——既直观看到生成过程，又清楚自己生成了什么，不必等全部完成。
- 复用现有各资源类型的生成接口（逐个调用），主要是前端把"批量等待"改成"按选择 + 逐项进度 + 逐项呈现"；后端生成逻辑本身不动。
**验证**：勾选若干类型 → 逐项生成、逐项出结果、进度可见；未勾选的不生成。

## 任务 3（问题 6）：资源推荐纳入生成成果
**改**：把「资源推荐」（联网聚合的外部资源）也纳入「生成成果」区一并展示，与生成的讲义/视频/图解等并列，用户在成果里能看到并打开推荐资源。
**验证**：生成成果区出现资源推荐条目，可查看/打开。

# 约束
复用现有资源生成接口 / 大屏 / 评估面板 / 设计令牌；不改既有接口签名（新增仅追加并同步文档）；Mock 兜底。

# 输出
现状说明 + 改动文件清单 + 接口文档增量（如有）+ 3 项验证结果 + 红线自检。完成即停。
