# B1 — 数据层 + 双角色认证 · 完成总结

> 阶段：B1（执行方案 V1.1）｜状态：✅ 完成（0 报错）｜日期：2026-06-10

## 1. 交付内容

- **数据层**：SQLAlchemy + SQLite，10 张表覆盖接口文档数据字典（第 2 章）与管理端模型（第 14 章），字段名严格对齐契约（对外 camelCase，列名 snake_case，schema 层映射）。
- **双角色认证**：JWT（PyJWT HS256）三接口 `login / forgot-password / logout`；登录响应含 `role + hasDiagnosed + hasGeneratedPath`（接口文档 3.1 + 15.1）；种子账号 `admin/admin123`、`learner_001/123456`。
- **鉴权依赖**：`require_admin`（非 admin → 1003）、`get_current_user`（无/失效 token → 1002）；退出登录经内存 jti 黑名单令牌失效。
- **日志脱敏**：手机号 / 邮箱掩码 `logging.Filter`，挂载 root 与 uvicorn 全部 logger（需求文档 7.4）。
- **幂等初始化**：建表 + 种子（6 核心知识点 + 6 课 + 2 账号 + 2 旅程），可重复执行不产生重复数据。
