### ③ KnowledgeGraph（10.1）

- `services/knowledge_graph.py`：12 节点（名称/基线掌握度与前端一致）+ 14 边静态种子；
- **category 不入库，每请求按 mastery 实时推导**：`passed→(0,100)`；
  `learning|pending-check→(1, min(种子值,60))`（与前端派生规则一致）；
  未开始高 value→2；`value<20`→3 知识盲区（`BLIND_SPOT_THRESHOLD=20`）；
- value 取掌握度 %；6 核心 KP 经 `KnowledgePoint.graph_node_id` 映射，6 个拓展节点恒按种子值推导。

### ④ Reinforce（9.2，LLMClient 双模式）

- `POST /reinforce`：错题 id 回查种子题库（未知 id 跳过）→
  `LLMClient.generate_reinforcement` → 每卡 `{questionId, point, recap, practice(QuizQuestion)}`；
- **mock**：确定性输出——nn 三题与前端 `WeakPointReinforce.tsx` 演示内容对齐
  （practice id 按契约 `{qid}-r`），库外题走确定性变式兜底（题干前缀【强化·变式】+
  选项轮转一位，option_id 随选项移动答案恒自洽）；
- **deepseek**：真实生成 + **critic 自洽审核**（`llm.audit_practice`：correct_answer
  必须在 options 中、multiple 全员存在、explanation 非空、题型/选项结构基本面），
  不自洽带审核反馈重试一次，仍失败 → `LLMGenerationError` → **2001/500**（复用 B5-b 映射）；
  service 层最终防线对 mock 产物同审（零成本，口径统一）。
