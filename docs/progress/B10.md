## 1. 交付内容

### ① 后端：`/workflow/execute` 支持 difficulty + 产物回写讲义缓存（11.1 / 8.2）

- **入参**：请求体补 `difficulty`（`入门|初级|高级`，缺省「初级」；非法 → `1001`），
  与既有 `targetJobId / kpId` 一致均可选（接口文档 11.1 已同步补充该字段与回写语义）。
- **回写闭环**（`workflow_runner._worker` + `resource.cache_lecture_from_workflow`）：
  工作流 **complete 且未降级** 时，把产物（`markdown + sources + hallucinationRate +
  workflowId`）按 `kp+difficulty` **覆盖写入** 讲义缓存（kind 与 8.2 同口径：
  mock=`lecture` / 真实=`lecture@<provider>`）→ 资源页讲义与大屏产物同源、workflowId 一致。
  **降级（degraded）产物不覆盖缓存**：旧讲义与其 workflowId 原样保留，仅留 WorkflowTrace。
  回写在后台线程 complete 帧之后提交，失败仅记日志、不向 WS 抛错帧（不影响已实时交付的结果）。
- **检索器同源**：execute 真实模式注入 `_retrieve_for_lecture`（与 `/resource/lecture` 同检索
  → 同生成），mock 模式传 None（确定性 mock 检索，演示快、可复现）。

### ② 后端：`/resource/lecture` 响应补 `workflowId`（8.2）

- 产出该份讲义的工作流 trace id：mock 直出（不经工作流）→ `null`；真实模式由讲义工作流
  预分配 id 并落 `WorkflowTrace`。**缓存命中返回缓存所属的 workflowId**；旧缓存（B10 前，
  无该键）读时统一补 `null`（向后兼容）。接口文档 8.2 已同步补充字段与跳转语义。

### ③ 前端·资源页讲义 Tab：重新生成闭环（仅联调渲染）

- 头部「🔄 重新生成」按钮 → **确认弹层**（提示「约需 20 秒」「完成后内容与溯源自动刷新」）
  → `POST /workflow/execute`（当前 kp + 当前难度档）→ **内嵌迷你进度**（复用 11.2 WS 订阅，
  显示当前阶段：学情诊断 / 资源生成 / 内容审核 / 已完成）→ complete 后**轮询讲义至命中本次
  workflowId**（等待后台回写提交）→ 自动刷新讲义 markdown 与**溯源徽章**（SourceTrace 改吃
  后端真实 sources，confidence 0-1 → 0-100 展示）。
- 旁「查看生成过程 →」链接（讲义带 workflowId 时显示）→ 写 `workflowNav` 后跳大屏回放该工作流。

### ④ 前端·Agent 大屏：实时目标选择 + 完成提示 + 回放（仅联调实时模式渲染）

- 实时模式新增**目标知识点 + 难度**下拉（默认沿用现有演示参数 `nn / 初级`），启动时以所选
  参数触发 `execute`；运行中禁用。
- complete 后：未降级 → toast「✓ 生成结果已更新至学习资源（kp 名）」+「去学习资源查看 →」
  跳转入口（设目标 kp 后导航资源页）；降级 → 页头轻提示「工作流降级，学习资源保留上一版本」。
- 从资源页「查看生成过程」进入 → 取 `GET /workflow/{id}` 完成态快照**回放**（页头「正在回放」徽提示）。

### ⑤ 约束遵守

- **演示模式零改动**：`simulateWorkflow` setTimeout 链一行未改；新 UI 全部 `USE_REAL_API`
  门控，mock 模式（USE_REAL_API=false）不渲染重新生成入口 / 实时选择 / 完成 toast，行为逐帧一致。
- **mock provider 闭环**：mock 工作流生成复用同一 `_lecture_markdown`，故 markdown 与直出逐字
  一致，回写后仅 sources/workflowId 变化——确定性产物照常回写（pytest 全程 mock 基线佐证）。
