# 问题 2：对话诊断重复同一问题
- 现象：用户答"学过一些"后，诊断 Agent 原样重发了上一个问题。
- 修复：问过的维度无论回答是否可抽取，都标记"已问"；遇到模糊回答时，做**低置信推断**或转向**下一维度（用不同措辞）**，**严禁原样重发同一句问题**。
- 顺带检查聊天气泡渲染：用户回答疑似被错误归属（出现"系统的学过一些"类前缀错位），修正气泡 role 归属。

# 问题 3：刷新后登出
- JWT token 持久化到 localStorage；应用启动时读取并恢复登录态（token 存在即恢复，过期则正常跳登录）。
- 与现有持久化 store（journey/portrait）风格一致。

# 问题 4："去学习资源"不跟当前进度
- 现象：学完第一节标已掌握后，"去学习资源"仍跳回第一节。
