2. **指标为当次样本实测**：LLM 生成有随机性（temperature 0.7），重跑 `make_report.py` 数值会小幅波动；
   多轮观测幻觉率落在 3–6% 区间，达标但非大幅冗余。讲义缓存内的逐份 `hallucinationRate`
   为生成时 critic 计算值，个别样本可能 ≥5%（均值口径达标）。
3. **mock 模式下指标语义降级**：mock 讲义为固定模板，三脚本仍可跑通（无 Key 链路验证），
   但数值不代表生成质量；报告会标注 provider。

   15.3 预处理、模板调优），无接口契约变更；3 个旧测试因 generation 模板新增 `{description}`
   占位符与 dev 库多难度缓存常态而适配。
5. 浏览器端（管理端 gauge 显示实测值、资源页 mindmap/diagram 仍走本地）未做自动化走查，
   建议评审时人工确认。
