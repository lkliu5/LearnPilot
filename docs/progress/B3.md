## 1. 交付内容

### RAG 管道（`app/rag/`，需求文档 4.3）

- **chunker.py**：标题感知 + 重叠窗口切片。识别 Markdown 标题维护层级栈，切片不跨标题边界；
  每个 chunk 记录 `source_document`（文档标题）与 `source_location`（`[页码 /] 章节路径 / 段落 N`）。
  边界鲁棒：空文档→`[]`；超长段落按句子聚合切分，单句仍超长则字符硬切；无标题→「正文 / 段落 N」。
  Token 估算沿用 4.3.1 口径（中文 1.5 字符/token、其余 4 字符/token）。
- **embeddings.py**：`bge-small-zh-v1.5`（sentence-transformers）。**延迟加载**（首次 embed 才加载，
  不阻塞 uvicorn 启动）；模型缓存目录 `settings.model_cache_dir`；**已缓存时 `local_files_only`
  离线加载**，规避 uvicorn/async 环境下 huggingface_hub httpx 客户端关闭导致的联网失败。
  加载失败自动降级为确定性哈希嵌入（256 维，L2 归一化），打 WARNING，保证无网络/无模型可跑。
- **vector_store.py**：Chroma 持久化集合（`PersistentClient`，cosine 空间）；chromadb 不可用时
  降级为 JSON 持久化的内存余弦库。统一接口 add/query/delete_by_document/get_all/count，
  距离统一转 0-1 相似度。
- **retriever.py**：BM25（rank_bm25，中英混合简易分词）+ 向量检索 → **RRF 融合**（4.3.2 口径，
  dense 0.7 / sparse 0.3 / rrf_k 60）。BM25 索引按库内容计数惰性重建。
- **reranker.py**：`bge-reranker-base`（CrossEncoder）二次打分，sigmoid 归一化到 0-1。
  **加载失败 / 推理异常自动降级**为仅 RRF 排序（归一化分），打 WARNING，接口仍返回 `code 0`。

### 管理端知识库接口（`app/api/v1/admin_kb.py` + `app/services/kb.py`，接口文档第 14 章）

| 接口 | 说明 |
|---|---|
| `POST /admin/kb/upload` | multipart 上传（pdf 经 pypdf 逐页 / md / txt），建文档记录（pending）+ 异步入库任务，返回 `taskId + documents` |
| `GET /admin/kb/documents` | 分页列表，支持 `keyword`（标题模糊）/ `status` 过滤 |
| `DELETE /admin/kb/documents/{id}` | 删除文档 + 同步清理 Chroma 向量切片；不存在 → `1004` |
| `POST /admin/kb/search-test` | 混合检索 → 重排，返回 `rerankerUsed` + chunk（含 `score`/`vectorScore`/`bm25Score`/`sourceLocation`） |

全部 `require_admin`（非管理员 → `1003`/403）；入库为异步任务（`taskId` 状态机，`GET /tasks/{taskId}`
轮询），重型向量化在 `asyncio.to_thread` 执行不阻塞事件循环；响应统一套 1.2 信封。

## 3. 启动 / 验证命令

```bash
cd backend
pip install -r requirements.txt          # 新增 chromadb / sentence-transformers / rank_bm25
python seed_kb.py                         # 一键灌库（首次会下载 bge-small-zh 模型到 data/models）
uvicorn app.main:app --reload --port 8000
pytest -q tests/test_chunker.py           # 切片边界测试
```

> `backend/data/models`；之后离线加载。无网络/无模型时全链路自动降级仍可跑通。

## 5. 边界确认 / 给后续阶段的约定

- **降级口径**：embedding（哈希 256 维）、vector_store（numpy 余弦库）、reranker（仅 RRF）三处
  均可独立降级，保证无网络/无模型时全链路跑通（CLAUDE.md「无密钥可跑通」纪律）。
  注：哈希降级维度 256 与真实 bge 512 不同——同一 Chroma 集合不可混用两种嵌入；正常运行
  （模型可加载）不会触发，演示前以 `seed_kb.py` 灌库即建立一致的 512 维集合。
- **离线加载**：模型已缓存时以 `local_files_only` 加载，规避 uvicorn/async 下 huggingface_hub
  httpx 客户端关闭导致的联网失败（本阶段联调中实测并修复）。
- **前端零改动**：本阶段纯后端 + 算法，未触碰 `frontend/src`。管理端前端在 **B4** 复用
  `SourceTrace` 展示 search-test 的 chunk + 分数 + 来源。
- **与 B5 衔接**：B5 的「RAG 检索 → 生成 Agent → 审核 Agent」直接复用 `get_retriever()`/
  `get_reranker()`；`/resource/lecture` 的真实 sources 由检索命中切片回填、hallucinationRate
  按 15.3 逐句接地口径计算。检索接口签名不变。
- **生产替换路径**（README 待 B8 汇总）：Chroma→Milvus、内存任务→Celery/Redis、
  本地 bge→托管向量服务；当前轻量栈满足 demo。
