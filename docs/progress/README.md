# 阶段验收日志

本目录保存已经发生的开发、修复、联调和验证记录，属于**生产过程固化日志资产**。

## 使用原则

- 新阶段完成后新增一份日志，不覆盖旧阶段。
- 日志中的“已完成”只代表当时版本；当前状态以
  [`../维护/当前工程状态.md`](../维护/当前工程状态.md) 和实际代码为准。
- 不在这里维护项目总进度、产品定位或长期待办。
- 同一任务的“CC 指令”和“完成结果”并存时，完成结果是主要验收证据。
- B0–B8 后的扩展阶段仍可保留，但命名需清晰并写明契约依据。

## 内容分组

- `B*.md`：原后端阶段与后续后端增强。
- `C*.md`：画像、学习流、个性化等扩展阶段。
- `CC-*.md`、`CC指令-*.md`：历史代理任务及结果。
- `feat-*.md`、`fix-*.md`：独立功能和修复。
- `联调-*.md`：前后端联调验收。
- 其余专题日志：媒体、文档学习、资源库、知识体系等阶段结果。

旧文件不再重新排号或改名，避免破坏 Git 历史和文档引用。
