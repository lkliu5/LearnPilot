## 3. 启动命令

```bash
cd backend
pip install -r requirements.txt
uvicorn app.main:app --reload --port 8000
# 健康检查：curl http://localhost:8000/api/v1/health
```

前端联调（已就绪，无需改动）：`cd frontend && npm run dev`，浏览器 `fetch('/api/v1/health')` 经 Vite 代理（`/api → :8000`）即可。

## 5. 设计说明 / 给后续阶段的约定

- **信封统一出口**：traceId 走 `contextvars` + `TraceIdMiddleware` 注入；端点显式 `return success(...)`，错误由 `main.py` 注册的 3 个异常处理器套信封。**B1+ 所有接口（含 WS/SSE 推送）一律复用 `app.core.envelope` 的 `success`/`fail`**，禁止裸返回。
- **错误码映射**（§1.3）：400→1001、401→1002、403→1003、404→1004、其余→5000；`2001`（Agent 生成失败）、`2002`（上游降级）留待对应业务阶段使用。
- **依赖最小化**：Chroma / SQLite / bge / LangGraph / JWT 等留到对应阶段（B1/B3/B5）再加入 `requirements.txt`。
- `config.py` 中 `llm_provider="mock"` 为 Mock-first 预埋占位，B2 接入 `LLMClient` 适配层时使用。
