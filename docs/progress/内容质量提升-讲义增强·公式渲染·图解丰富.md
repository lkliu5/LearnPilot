| 项 | 改前现状 | 问题 |

## 二、改动文件清单

### 后端（6 个）
- **`backend/app/core/lecture_content.py`（新增）**：讲义内容合成引擎。6 核心 KP（nn/ml/dl/cnn/transformer/finetune）精写知识原子（直觉类比·核心原理+**标准 LaTeX 公式**·公式推导·底层原理·具体例子·**可运行代码**·常见误区·对比延伸）；未收录 KP 按 description 同构合成（不臆造公式，防幻觉）。`compose_lecture(name, difficulty, description, tier)` 纯函数确定性，按 `depth∈{0,1,2}` 组织"概念引入→核心原理→例子→代码→误区→小结"递进结构；`tier`（画像能力档）为个性化主控。
- **`backend/app/core/llm.py`**：
  - `_lecture_markdown` 改为委托 `compose_lecture`，新增可选 `tier` 形参（向后兼容 3 参调用，B5b/B10 契约不回归）；
  - `generate_lecture` / `_mock_generation` 透传 `tier`/`depthTier`；
  - `_DIAGRAM_TEMPLATES` 丰富化：nn/ml/dl 横向训练回路（flowchart LR，含反馈边）、cnn/transformer 用 **flowchart TD**（transformer 带 `subgraph` 编码器块）、finetune 用 **mindmap** 谱系；
  - `_generic_diagram`（新）按 description 动态合成（含"分类/组成"→层次图 graph TD，否则流程图，节点形状轮换）；
  - `_clean_mermaid` 放宽受支持图型白名单（flowchart/graph/mindmap/classDiagram/…）；`_deepseek_diagram` 提示改为"按内容自选最贴切图型"。
- **`backend/app/services/prompts.py`**：`generation` 默认模板增强（六段递进结构 + 标准 LaTeX 要求 + 新增 `{learnerProfile}` 占位符；防幻觉铁律不变）；新增**历史默认平滑升级**机制（库内仍是旧默认的行下次读取自动升级，管理员 PUT 自定义不被覆盖）。
- **`backend/app/agents/generator_agent.py`**：`run_generator` 新增 `learner_profile` / `depth_tier` 入参并注入 variables。
- **`backend/app/workflows/learning_workflow.py`**：新增 `_ability_tier(portrait, kp_id, kp_name)`（画像能力分→advanced≥70 / beginner≤35 / basic / None）；`generation_node` 读当前用户画像派生 tier 与画像文本传入生成。
- **`backend/app/services/resource.py`**：`generate_lecture`（前端实际调用路径）改为**按请求用户画像个性化**——派生 tier 传入 mock 生成，缓存按 tier 分档隔离（`lecture#advanced` 等；tier=None 维持 `lecture`，直出契约不回归），使不同用户取到深度不同的讲义且互不覆盖。

- **`frontend/package.json` / `package-lock.json`**：新增 `remark-math@6`、`rehype-katex@7`、`katex@0.16`。

### 任务2 · 公式渲染（截图 `docs/verify/screenshot-formula-katex.jpeg`）

- 注意力 $\mathrm{Attention}(Q,K,V)=\mathrm{softmax}(QK^\top/\sqrt{d_k})V$（块级）；
