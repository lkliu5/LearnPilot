# 任务 2：接真实规划 Agent（若现状为 Mock）
按赛题功能 3 实现真实学习路径规划：
- **真实规划 Agent**：输入 = 真实画像（StudentPortrait）+ 知识掌握度（Mastery）+ 学习目标/目标岗位；输出 = **科学、有步骤顺序的个性化学习路径**，明确"学什么、什么顺序、为什么这样排"。经 LLMClient（默认模型即可，**无需星火**）。

- **保留 Mock 兜底**：无密钥时给占位路径可跑通，演示稳定性优先。
- 沿用既有缓存/异步任务结构（若有），首次生成后命中缓存。

5. Mock 模式无密钥仍可跑通；
6. 全量测试通过、既有接口回归未变。
