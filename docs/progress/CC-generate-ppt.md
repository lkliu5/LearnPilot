# CC 指令 · 生成软件杯参赛介绍 PPT

> 目标：产出一份用于软件杯答辩/提交的演示 PPT（.pptx）。要求专业、有重点、用真实项目内容，不是满屏文字的流水账。

═══════════════════════════════════════════════════════════════

# 角色
资深演示设计师 + 工程师。本会话生成软件杯参赛 PPT（.pptx），用 python-pptx（或可用的 pptx 技能）实现。

# 内容来源（必须用项目真实内容，禁止杜撰）
从仓库读取真实信息填充：`docs/` 下的接口文档 / 进度文档 / 指标报告（metrics-report）、已实现的功能清单、真实指标（幻觉率 <5%、适配率、覆盖率等）、真实技术栈（React+FastAPI+LangGraph+Chroma+RAG+DeepSeek）。数据要和系统实际一致。

# 结构（12 页，对应评分维度：应用价值35% / 功能45% / 文档10% / 视频PPT10%）
1. **封面**：智学中枢 · 多智能体个性化学习平台 + 一句话定位 + 队伍信息。
2. **痛点与价值**：传统学习千人一面 + AI 生成易幻觉 → 我们的价值（因材施教 + 可信生成）。
3. **整体架构**：一张架构图（前端/后端/多智能体/RAG/数据），明确标注多智能体框架 LangGraph。
4. **核心功能 1 · 对话式画像**：摒弃表单、6 异质维度、随学随新、防幻觉低置信。
5. **核心功能 2 · 多智能体资源生成**：LangGraph 五节点（诊断→检索→生成→审核→决策）+ 重试降级 + 逐句 grounding；放真实幻觉率。
6. **核心功能 3 · 个性化学习路径**：不同画像不同路径、薄弱优先、精准推送。
7. **核心功能 4/5 · 智能辅导 + 学习评估**：按需资源生成 + 多维过程评估。
8. **创新亮点**：①真实多智能体协同（非串行模拟）②防幻觉 + 内容安全双保险 ③费曼+康奈尔学习闭环 ④对话式画像。
9. **学习方法闭环**：康奈尔笔记 → 费曼讲解 → 阶段测试通关（一张闭环图）。
10. **技术亮点与指标**：RAG 管线 + 真实指标（幻觉率/适配率/覆盖率，用大字数字）。
11. **工程与合规**：开源依赖与协议、AI 辅助开发（Claude Code + DeepSeek）、内容安全机制、测试覆盖。
12. **总结与展望**：成果回顾 + 揭榜挂帅（资源/岗位聚合）展望。

# 设计强约束（关键，避免做成文字墙）
- **每页 ≤5 个要点，每点一行短语**，绝不整段文字；信息靠"标题 + 关键词 + 视觉元素"。
- **重点页用图，不用字**：架构图、五节点工作流图、学习闭环图、指标用超大字号数字呈现。
- **统一视觉系统**：固定一套配色（建议沿用产品的 米色/navy/绿，或专业科技风深色），统一字体、统一标题版式、统一页脚页码。
- **每页配 speaker notes**（演讲备注），写清这页要讲的话，方便答辩。
- **留产品截图位**：在功能页留出截图占位框并标注"〔此处放 XX 界面截图〕"；如能用 playwright 截取运行中界面更好。
- 差异化亮点（真实多智能体/防幻觉/学习闭环/对话画像）要在创新页和封面副标题突出。

# 输出
`docs/软件杯介绍.pptx` + 一句话说明每页要点。完成即停。
