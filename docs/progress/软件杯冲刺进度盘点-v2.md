## 四、推荐冲刺顺序

```
1. 先清 P0 合规里"快的" ── AI Coding 说明 + 开源协议标注（半天内可完，且必交）
2. 确认三个"疑似没做" ── 内容安全过滤 / 苏格拉底真实 / S9 前端 surfacing
3. 补内容安全过滤（若缺，赛题硬要求）+ 苏格拉底切真实
4. 加分项 ── S4 岗位匹配 / S5 自定义课程 / 功能4多模态答疑 / 功能5行为跟踪（按余力）
5. 收尾 ── 录 7 分钟演示视频 + 做 PPT + 系统/测试文档收口
```

**判断原则**：P0 合规项虽然不"酷"，但漏了直接扣 10%（文档）+ 影响资格；而核心功能分（45%）大头已经拿下。所以**冲刺前期应优先把必交合规项和三个"疑似没做"清掉**，再用剩余时间堆加分项，最后留足时间给视频/PPT（这俩占 10% 且最花时间）。
