## 二、时长估算规则（合理估算·非真实计时）

| 维度 | 规则 |
|---|---|
| **每点预计时长** `estimatedMinutes` | 层级基线（入门 60 / 进阶 120 / 前沿 180 分钟）+ 展示难度微调（入门 −15…精通 +45），约束 **45 ~ 240 分钟**、取整 15 分钟。「入门较短、前沿较长」，且随基础分自适应难度略变。 |
| **整条路径周期** `cycleWeeks/cycleDays` | `pacePerDay`（快速概览型 2/天、其余 1/天）→ `cycleDays=⌈总数/每日⌉`、`cycleWeeks=⌈天/7⌉`。 |
| **总时长** | `totalMinutes=Σ estimatedMinutes`、`totalHours=totalMinutes/60`。 |
| **进度呈现** | `learnedCount/totalCount`（真实通过）+ `spentMinutes`（completed 计满、in_progress 按进度折算）+ `completionPct`（时长加权）。 |
| **节奏建议** `pacing` | 「建议每天 1(-2) 个知识点，预计 N 周（约 D 天）学完」。 |

**目标聚焦选点**：`learning_goal + target_job_name` 关键词命中板块（大模型→LLM / 视觉→CV /
生成扩散→GEN / 智能体→AGT / 强化→RLX / 深度学习→DL / 数据分析→ML）→ 该板块知识点纳入，
补齐**先修闭包**（可学）、按「聚焦优先 / 层级由浅入深 / 先修序」裁剪到 **≤ 12 步**；
**无目标/无命中 → 回落 6 核心主干（与旧行为字节级一致，零回归）；6 核心始终作主干。**
