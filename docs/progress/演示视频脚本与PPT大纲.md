# 智学中枢 · 演示视频脚本（≤7 分钟）+ PPT 大纲

> 用于软件杯初赛提交。视频严格 ≤7 分钟；脚本按"画面/操作 + 旁白要点 + 时长"编排。
> 录制建议：真实演示为主，关键链路（工作流/评估/防幻觉）一定要露真实数据，别用静态截图糊弄。

## 一、演示视频脚本（目标 6:40，留 20s 余量）

### 0:00–0:35 ｜ 钩子 + 痛点
- **画面**：平台首页一扫而过 → 定格标题"智学中枢"。
- **旁白**：传统在线学习的资源千人一面，AI 生成内容又常有幻觉、不可信。我们要解决的是——如何让 AI **真正因材施教**，并且**生成的每一句都可溯源、可信**。这就是「智学中枢」：一个多智能体驱动的个性化学习平台。

### 0:35–1:35 ｜ 核心一：对话式画像（摒弃表单）
- **画面**：进入画像诊断，**真实打字对话几轮**；右侧 6 维画像随对话 0→6 一格格填充。
- **旁白**：我们摒弃了填表式画像，改用对话——系统在自然交流中构建**知识基础、认知风格、易错点、学习目标、先验经验、学习节奏** 6 个异质维度。注意"易错点"这类推断维度标了**低置信**，这是我们防幻觉理念的体现：**不确定的，绝不编造**。诊断完成弹出确认画像，随学随新。

### 1:35–3:00 ｜ 核心二：多智能体协同 + 真实工作流（重头戏）
- **画面**：触发 Agent 工作流大屏，**实时**看节点逐个点亮：诊断→检索→生成→审核→决策；**制造一次审核不通过**，展示在 generation↔validation 间**真实回环重试**后降级。
- **旁白**：这是真实的 LangGraph 五节点协同，不是动画。领域知识生成 Agent 产出讲义后，内容审核 Agent 基于 RAG 知识库**逐句接地校验幻觉率**，超阈值就打回重生成——你看到的回环就是真实的重试。最终**幻觉率压到 5% 以下、sources 可溯源到具体文档**。
- **画面**：跳到生成的讲义，点开 sources、看幻觉率数值。

### 3:00–3:40 ｜ 核心三：个性化学习路径
- **画面**：展示两个不同画像生成的**不同路径**（薄弱点优先、已掌握后置）。
- **旁白**：规划 Agent 依据真实画像与掌握度打分排序——基础薄弱的从头学，已掌握的自动后置，每一步精准推送对应资源。**不同的人，不同的路径。**

### 3:40–4:50 ｜ 核心四：学习方法闭环（差异化亮点）
- **画面**：进入"有序学习"，走一遍**费曼+康奈尔**流：康奈尔三栏记笔记 → 费曼讲解（向 AI 讲，AI 指出知识缺口）→ 末尾**阶段测试通关**点亮已掌握。
- **旁白**：我们把学习方法做进了产品——康奈尔笔记结构化输入、费曼讲解倒逼理解、最后用阶段测试**通关才算掌握**。这是一条"学—记—讲—测"的科学闭环，真正对应赛题的因材施教。

### 4:50–6:00 ｜ 加分亮点速览（快节奏蒙太奇）
- **画面 + 旁白**（每项约 12 秒）：
  1. **智能辅导**："我没懂"→ 系统给针对性资源清单，勾选即按需生成；
  2. **学习评估 Agent**：基于真实做题行为的多维评估 + 动态调整建议；
  3. **岗位匹配**：对接目标岗位算匹配度 + 能力缺口；
  4. **内容安全过滤**：生成内容统一过敏感/违规检测，且不误伤学术术语；
  5. **资源联网聚合**：可联网搜索优质学习资源、AI 评分排序。

### 6:00–6:40 ｜ 技术与合规收尾
- **画面**：架构图一闪 + 指标看板（幻觉率/适配率/覆盖率）。
- **旁白**：技术上，React + FastAPI + LangGraph + Chroma + RAG 全栈自建；多智能体框架明确、测试数据自建完整课程知识库。编程使用 Claude Code、推理模型 DeepSeek，开源依赖均已标注。**智学中枢——让 AI 因材施教，让每一份学习内容都可信。**

> **时间控制提示**：核心二（工作流）是最有说服力的，给足时间；加分项用快节奏带过；总时长务必卡在 7 分钟内。

## 二、PPT 大纲（对应评分维度）

> 评分：应用价值 35% / 功能实现 45% / 文档 10% / 视频PPT 10%。PPT 要把"价值 + 功能 + 创新 + 技术"讲透。

1. **封面**：智学中枢 · 多智能体个性化学习平台 + 一句话定位 + 队伍信息。
2. **痛点与应用价值**（撑应用价值分）：千人一面 + AI 幻觉两大痛点 → 我们的价值主张（因材施教 + 可信生成）。
3. **整体架构**：前端/后端/多智能体/RAG/数据 一张架构图；明确标注**多智能体框架（LangGraph）**。
4. **核心功能 1 · 对话式画像**：6 异质维度、随学随新、防幻觉低置信。
5. **核心功能 2 · 多智能体资源生成**：LangGraph 五节点 + 审核重试降级 + 逐句 grounding（放真实指标）。
6. **核心功能 3 · 个性化学习路径**：因人而异、薄弱优先、精准推送。
7. **核心功能 4 · 智能辅导**（加分）：按需资源生成。
8. **核心功能 5 · 学习评估**（加分）：多维过程评估 + 动态调整。
9. **创新亮点**：①真实多智能体协同（非串行模拟）②防幻觉+内容安全双保险 ③费曼+康奈尔学习方法闭环 ④对话式画像。
10. **技术亮点与指标**：RAG 管线、真实幻觉率 <5%、适配率、覆盖率；性能/可靠性。
11. **工程与合规**：开源依赖与协议、AI 辅助开发说明（Claude Code + DeepSeek）、内容安全机制、测试覆盖。
12. **总结与展望**：成果回顾 + 揭榜挂帅方向（资源/岗位聚合）展望。
