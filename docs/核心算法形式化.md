# 算法一 · CPDP：能力-偏好双驱动路径规划算法
## (Capability-Preference Dual-driven Path-planning)

> 对应模块：backend/app/agents/planner_agent.py
> 一句话：在知识图谱（带先修依赖的 DAG）上，以「能力画像定内容与顺序、偏好画像定呈现形式」双驱动，在时间预算约束下规划个性化学习路径。

## 1.1 问题建模

将知识体系建模为**有向无环图（DAG）** G = (V, E)：
- 节点 V = {k₁, k₂, …, kₙ}，每个知识点 kᵢ 含：能力实测得分 aᵢ∈[0,100]、层级 lᵢ∈{入门,进阶,前沿}、预计时长 tᵢ；
- 有向边 E：kᵢ → kⱼ 表示 kᵢ 是 kⱼ 的先修知识点（prerequisite）。

目标：为学习者规划一个满足先修约束、优先补齐薄弱点、贴合学习偏好、在时间预算内的有序知识点序列 P = [k_{π(1)}, …, k_{π(m)}]。

## 1.2 能力驱动：薄弱度评分与优先级

对每个候选知识点 kᵢ，定义**掌握缺口（mastery gap）**：

```
gap(kᵢ) = 1 − aᵢ / 100
```

综合优先级评分（薄弱越大、越贴合目标、层级越合适 → 分越高）：

```
score(kᵢ) = w_g · gap(kᵢ) + w_t · relevance(kᵢ, goal) + w_l · levelFit(kᵢ, aᵢ)
```

其中：
- gap(kᵢ)：掌握缺口，薄弱点优先（薄弱前置、已达标 aᵢ≥θ 后置为复习，θ=70）；
- relevance(kᵢ, goal)：与学习目标/板块的相关度（目标聚焦，命中目标板块加权）；
- levelFit：层级适配（避免给零基础直接排前沿点）；
- w_g, w_t, w_l：权重（默认 0.5 / 0.3 / 0.2）。

## 1.3 先修约束：拓扑有序化

在按 score 排序的同时，用**拓扑排序（Kahn 算法）保证先修顺序**——任何知识点必须排在其所有先修点之后：

```
∀ (kᵢ → kⱼ) ∈ E,  position(kᵢ) < position(kⱼ)
```

## 1.4 偏好驱动：呈现形式映射

偏好画像不影响"学什么/顺序"，而决定**每个节点默认推荐的资源形式** r(kᵢ)：

```
r(kᵢ) = f_pref(style)
  图像型(visual)   → 图解 / 思维导图
  案例型(example)  → 例题 / 代码实操
  概览型(overview) → 思维导图 / 概览讲义
  细钻型(detail)   → 详细讲义（六段递进）
```

## 1.5 时间预算约束

给定时间预算 T_budget，贪心选取高分知识点直至累计时长逼近预算，输出路径周期估计：

```
Σ tᵢ ≤ T_budget,   cycleDays = ⌈m / pacePerDay⌉
```

## 1.6 伪代码

```
输入：知识图谱 G(V,E)，学习者画像 Φ={能力 a, 偏好 style, 目标 goal}，时间预算 T
输出：个性化路径 P（有序，带时长/形式/理由）

1. 候选集 C ← 按 goal 目标聚焦选相关板块知识点 + 其先修闭包
2. for kᵢ in C:
3.     gap ← 1 − aᵢ/100
4.     score(kᵢ) ← w_g·gap + w_t·relevance(kᵢ,goal) + w_l·levelFit(kᵢ,aᵢ)
5. C ← TopologicalSort(C, E)              // 先修约束（Kahn）
6. P ← 在拓扑序内按 score 加权排序（薄弱前置、已达标后置）
7. 时间预算裁剪：累计 Σtᵢ ≤ T，得 m 步
8. for kᵢ in P:
9.     r(kᵢ) ← f_pref(style)              // 偏好定呈现形式
10.    reason(kᵢ) ← 生成规划理由（"因你 X 薄弱，优先安排"）
11.    tᵢ ← 层级估时（入门60/进阶120/前沿180 分，约束45–240）
12. 输出 P（节点+顺序+时长+形式+理由+周期/进度）
13. 画像指纹变化时触发重算（缓存失效）
```

## 1.7 创新点
- **双驱动解耦**：能力定"学什么/顺序"、偏好定"怎么呈现"，两维独立——真因材施教；
- **知识图谱 DAG + 拓扑排序**保证先修科学性；
- **时间线维度**：预计时长/周期/进度/节奏，规划可执行、可感知；
- **画像指纹驱动增量重算**：画像变则路径实时更新。

# 算法二 · GCG：接地置信门控算法
## (Grounded Confidence Gating for Hallucination Suppression)

> 对应模块：backend/app/services/grounding.py + generator/critic Agent + content_safety
> 一句话：对 AI 生成的教育内容逐句做 RAG 接地校验，计算幻觉率，按三级置信门控决定「通过 / 降级 / 打回重生成」，从生成源头抑制幻觉。

## 2.1 逐句接地（Sentence-level Grounding）

将生成内容 D 切分为句子集合 S = {s₁, …, sₙ}。对每个句子 sⱼ，在 RAG 检索到的证据片段集合 C = {c₁, …, cₘ} 中计算最大语义支持度：

```
support(sⱼ) = max_{cₖ ∈ C} sim(sⱼ, cₖ)
```

sim 为语义相似度（嵌入向量余弦）。句子被判为"接地"当且仅当：

```
grounded(sⱼ) = 1  if support(sⱼ) ≥ τ_g   else 0     (τ_g 为接地阈值)
```

## 2.2 幻觉率（Hallucination Rate）

整篇内容的幻觉率定义为未接地句子占比：

```
H(D) = 1 − ( Σⱼ grounded(sⱼ) ) / n
```

H(D) 越低越可信（越多句子有据可依）。

## 2.3 内容类型自适应权重

不同内容类型对"接地"的要求不同（代码可执行验证、纯陈述靠 RAG、公式靠符号），综合置信度融合规则检测与接地检测：

```
Conf(D) = α(type) · (1 − H(D)) + β(type) · RuleCheck(D)
```

- type ∈ {讲义/代码/测验/混合}，α+β=1，按类型自适应；
- RuleCheck：事实一致性、引用完整性、格式规范等规则分。

## 2.4 三级置信门控（Confidence Gating）

```
Gate(D) =
   PASS         if Conf(D) ≥ θ_high        → 通过，输出（带溯源标注）
   DEGRADE      if θ_low ≤ Conf(D) < θ_high → 保留高置信部分 + 低置信标注/逐句降级
   REGENERATE   if Conf(D) < θ_low          → 打回生成 Agent 重新生成（≤N 次）
```

- 超过 N 次仍不过 → 降级终态（如实告知"审核未完全通过"），不硬出可能错的内容。

## 2.5 教育性语境豁免（内容安全，正交于幻觉）

内容安全检测叠加**语境感知豁免**，区分"讨论危险"与"指导危险"：

```
Block(sⱼ) = Sensitive(sⱼ) ∧ ¬EduContext(sⱼ) ∧ ¬(Sensitive ∧ RecipeSignature(sⱼ))
```

- Sensitive：命中敏感共现规则；
- EduContext：句中含"拒绝/防范/识别/史论/例如"等教育框架词 → 豁免（讲 AI 安全引用"应拒绝造危险品"不误拦）；
- RecipeSignature：真实操作步骤签名（"取N克/第一步/配方为"）→ 即使带教育框架也拦（逃逸防护）。

## 2.6 伪代码

```
输入：生成内容 D，RAG 证据集 C，内容类型 type
输出：Gate 决策（通过/降级/重生成）+ 幻觉率 H + 溯源

1. S ← 分句(D)
2. for sⱼ in S:
3.     support(sⱼ) ← max_{cₖ∈C} sim(sⱼ, cₖ)
4.     grounded(sⱼ) ← [support(sⱼ) ≥ τ_g]
5.     cite(sⱼ) ← argmax cₖ（溯源来源）
6. H(D) ← 1 − mean(grounded)
7. Conf(D) ← α(type)·(1−H) + β(type)·RuleCheck(D)
8. // 内容安全逐句
9. for sⱼ in S:
10.    if Sensitive(sⱼ) and not EduContext(sⱼ): mark_block(sⱼ)
11.    if Sensitive(sⱼ) and RecipeSignature(sⱼ): mark_block(sⱼ)  // 逃逸防护
12. Gate ← 三级门控(Conf(D), θ_high, θ_low)
13. if Gate == REGENERATE and retries < N: 打回重生成; goto 1
14. 输出 Gate 决策 + H(D) + 逐句溯源标注 + 安全降级结果
```

## 2.7 创新点
- **逐句接地 + 可量化幻觉率**：不是"感觉可信"，而是真算 H(D)，可复现、消融实验验证；
- **类型自适应门控**：不同内容类型不同权重，比一刀切更精准；
- **生成源头抑制**：不合格打回重生成，而非事后过滤；
- **语境感知内容安全**：区分讨论/指导，教育性豁免 + 逃逸防护——教育场景独有的精细度。

# 附：两算法在系统中的位置（答辩可讲）

```
学习者画像 Φ
    │
    ├─[CPDP]→ 个性化学习路径（能力定内容/偏好定形式/时间线）
    │
    └─→ 多智能体生成内容 D
            │
            └─[GCG]→ 逐句接地 + 置信门控 + 语境安全 → 可信输出（带溯源）
```

- **CPDP** 解决"学什么、怎么学"的个性化；
- **GCG** 解决"内容可不可信"的可信性；
- 两者一前一后，构成"个性化 + 可信"的双核心。
