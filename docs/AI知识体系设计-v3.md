## 九、知识图谱脉络

```
ML基础 → DL核心
   ├→ CV视觉 → ViT/多模态
   ├→ LLM大模型 → 微调/RAG/对齐
   │      ↘
   ├→ ★GEN生成式扩散（VAE/GAN → DDPM → LDM/SD → ControlNet/视频3D）
   │      ↗（多模态、U-Net 交叉）
   ├→ ★AGT智能体（概念→架构→记忆/规划/工具→多智能体→编排→前沿）
   └→ RL强化学习 + 前沿伦理（蒸馏/联邦/XAI/安全）
```

GEN 与 CV/LLM 多处交叉（U-Net、多模态、Transformer），AGT 与 LLM/RAG 交叉，形成立体知识网。

## 十、审校要点

1. **78 个 / 7 板块 合适吗**？GEN(13) 和 AGT(13) 深化是否到位？还要加吗（如 GEN 补 Imagen/DALL-E 对比、一致性模型；AGT 补记忆细分、Agent 安全）？
2. **Diffusion 配图点（🖼）**：GEN 板块大量标了配图，扩散过程/U-Net/SD架构/ControlNet 效果这些图能显著提升感官——确认这些点值得重点配图。
3. **先修关系**：GEN 依赖 VAE/GAN/U-Net，AGT 依赖 LLM/RAG，跨板块先修是否合理（需专业把关）。
4. **与项目呼应**：AGT 板块（尤其五层架构 AGT-2、多智能体编排 AGT-9）正好呼应你项目本身的多智能体设计——学这些知识点时可以关联"本平台就是这么做的"，很有说服力。
