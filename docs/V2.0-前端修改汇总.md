## 一、Design System 全局变量

| `--gray-50` ~ `--gray-900` | `#f8fafc` ~ `#0f172a` | Slate 灰色系 |

| `--bg-card` | `rgba(255,255,255,0.70)` | 卡片玻璃背景 |
| `--bg-card-hover` | `rgba(255,255,255,0.85)` | 卡片 hover 背景 |

## 九、视觉规范总结

### Glassmorphism 玻璃效果标准
```css
background: rgba(255, 255, 255, 0.6~0.7);
backdrop-filter: blur(20~24px);
-webkit-backdrop-filter: blur(20~24px);
border: 1px solid rgba(255, 255, 255, 0.4~0.5);
box-shadow: var(--shadow-sm);
```

### 发光效果标准
```css
/* 蓝色发光 */
box-shadow: 0 0 8px rgba(37, 99, 235, 0.6), 0 0 16px rgba(37, 99, 235, 0.3);

/* 绿色发光 */
box-shadow: 0 0 8px rgba(16, 185, 129, 0.6), 0 0 16px rgba(16, 185, 129, 0.3);

/* 紫色发光 */
box-shadow: 0 0 16px rgba(124, 58, 237, 0.4);
```

### Hover 交互标准
```css
transform: translateY(-2~4px);
box-shadow: var(--shadow-float), 0 0 20px rgba(37, 99, 235, 0.1~0.15);
```
