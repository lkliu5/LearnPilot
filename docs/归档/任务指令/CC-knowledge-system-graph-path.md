## 会话二 · 知识图谱分层可视化（大点→点击展开小点）

> 会话一录入后做。

═══════════════════════════════════════════════════════════════
# 角色
资深前端工程师。禁改既有接口签名。本会话把知识图谱升级为分层/分板块可视化，承载 78 点。

# 背景
知识点扩到 78 个，一次性平铺会糊成一团。需分层展示：先看大结构，点击展开细节。

# 任务
1. **分层展示**：
   - **第一层**：7 大板块（ML/DL/CV/LLM/GEN/AGT/RL·X）作为主节点/分区展示，清晰概览；
   - **第二层**：点击某板块 → 展开该板块内的知识点（含层级/先修连线）；
   - **第三层/详情**：点击某知识点 → 显示其简介、先修、层级，可跳去学习该点（生成资源）。
2. **先修关系连线**：知识点间按 prerequisites 画依赖连线（同板块内 + 跨板块交叉如 ViT/多模态/GEN依赖）；层级用颜色/位置区分（入门→进阶→前沿）。
3. **可读性**：避免节点重叠糊成一团；支持缩放/拖拽/收起展开；板块用不同色系；套现有设计令牌、深浅主题正常。
4. 复用现有知识图谱功能与数据（读会话一录入的体系）；mock 兜底有示例数据。

# 验证（截图）
1. 第一层清晰显示 7 板块；点击板块展开其知识点；点知识点看详情、可去学习；
2. 先修连线正确、层级可辨、不糊成一团；缩放/拖拽正常；
3. 深浅主题正常、tsc 干净、0 console error、无回归。

# 输出
改动文件清单 + 验证结果 + 红线自检。完成即停。

## 会话三 · 路径规划细化 + 学习时间线/节奏/进度

> 会话一录入后做（可与会话二并行）。

═══════════════════════════════════════════════════════════════
# 角色
资深全栈工程师。禁改既有接口签名。本会话细化学习路径规划，加入时间线维度。

# 背景
路径现在是"学什么+顺序"（planner 按薄弱点+先修）。要在更大的 78 点知识树上规划得更细，并新增时间维度。

# 任务
1. **在新体系上规划**：planner 在 78 点知识树上按 薄弱点优先 + 先修依赖 + 学习目标 规划路径；路径可按板块/目标聚焦（不必一次铺满78点，按用户画像和目标裁剪出合理长度的路径）。
2. **时间线（新增·重点）**：
   - **每个知识点预计时长**（如"神经网络基础 · 约 2 小时"，按层级/难度估算：入门较短、前沿较长）；
   - **整条路径预计周期**（如"预计 2 周学完 · 共 12 个知识点 · 约 20 小时"）；
   - **进度呈现**：已学/总数、已花时长/预计时长、完成百分比；
   - 学习节奏建议（如"建议每天 1-2 个知识点"）。
3. **路径可视化**：路径以带时间线的形式呈现——节点 + 预计时长 + 先修顺序 + 当前进度位置 + 下一步高亮。复用现有路径展示，增强时间维度。
4. 沿用现有 planner 消费能力分/偏好、画像指纹缓存（画像变才重算）；mock 兜底。

# 约束
不改既有接口签名（时长/周期/进度为追加字段）；不破坏现有 planner 逻辑与路径展示既有功能；预计时长用合理估算规则（按层级），不需真实计时。

# 验证（截图）
1. 路径在新体系上规划、按目标/薄弱点裁剪合理长度；两个不同画像用户路径不同（沿用之前个性化验证）；
2. 每知识点有预计时长、整条路径有预计周期/总时长、进度百分比、节奏建议；
3. 路径带时间线可视化清晰、当前进度/下一步可辨；
4. 既有接口无回归、tsc 干净、0 console error。

# 输出
现状 + 时长估算规则 + 改动文件清单 + 接口文档增量 + 验证结果 + 红线自检。完成即停。
