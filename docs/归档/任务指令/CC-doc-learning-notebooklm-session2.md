# 任务

## 1. 多文件上传 + 多选统一生成
- 支持上传多个文档（PDF / 文本 / md），左栏来源列表管理多文档；
- 支持勾选多个文档，基于选中的多个文档**统一生成**（合并这些文档的知识源/检索范围再生成）；单选时行为同现在；
- 多文档合并仍走隔离逻辑（可为一次生成建一个合并检索范围），与内置库隔离、互不污染。

## 2. 文档问答（即问即答，核心新功能）
- 新增"和文档对话"：用户就选中的文档（们）提问 → 基于该文档向量集合检索 → **流式即问即答**；
- 复用现有 RAG + 流式问答能力（文档辅导 / 苏格拉底流式那套），回答**严格基于文档内容、防幻觉、标出处溯源**（答案行内或末尾标来源，像文档辅导一样）；
- 实时性：流式逐字回答；中栏保留问答历史；
- 明确：问答是"理解文档"，不是"对话生成资源"；生成资源仍走右栏按钮，两者独立并存。

## 3. NotebookLM 式三栏布局
- **左栏 · 来源与概览**：
  - 上传 / 多文档列表 / 勾选；
  - **文档概览放在左栏**：选中某文档后，在左栏展示该文档的概览 / 总览概况（是什么、讲了什么、核心结构、关键点）——即现有"文档概览 · AI 速读"内容，从原位置挪到左栏，让左栏成为"关于来源的信息区"。复用现有概览能力，不重做，只调整展示位置。
- **中栏 · 问答**：和文档即问即答（流式、基于文档、溯源），是页面主交互区，保留问答历史。
- **右栏 · 生成**：点击生成讲义 / 视频 / 图解 / 思维导图 / 练习题 / 闪卡，生成完可点开查看，进"我的资源库"可下载（复用现有生成与下载）。
- 用项目现有设计令牌 / 风格（不照抄 NotebookLM 配色），深浅主题正常，响应式合理（窄屏三栏可堆叠 / 折叠）。

# 约束
