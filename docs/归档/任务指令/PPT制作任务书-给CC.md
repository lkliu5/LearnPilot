## 三、图形元素

### 六边形图标（样图核心元素）
- 流程节点用**六边形**（不是圆形），内含线性图标
- 每个六边形：渐变填充 + 发光边框 + 编号（01/02/03…）
- 六边形之间用**箭头连接**（发光渐变箭头）

**多智能体流程的六边形**：
```
01 诊断(听诊器) → 02 检索(放大镜) → 03 生成(笔) → 04 审核(盾牌·金色高亮) → 05 决策(分支)
```
> **审核 Agent 用金/橙色突出**——它是我们的差异化，视觉上就要不一样

### 卡片（架构分层用）
- 左侧：**圆形图标底**（不同色系）+ 线性图标
- 右侧：标题（白色粗体）+ 描述（浅蓝，2 行内）
- 卡片：渐变底 + 发光边框 + 微阴影
- **左侧色条**标识层级

### 数据展示
- 大数字用**青色 `#00d4ff` + 超大字号（48-60pt）**
- 单位/说明用小字浅蓝
- 进度条/柱状图：青绿渐变 + 发光

### 装饰元素
- 页面四角：科技感线条/网格
- 背景：淡淡的电路板纹理或粒子（透明度 5-10%，别喧宾夺主）
- 分隔线：渐变发光线（不用实线）

## ⚠️ 避坑提醒
1. **别太花** —— 样图的发光/装饰是有节制的，主体信息清晰。别加太多粒子/线条，喧宾夺主。
2. **字要少** —— PPT 上是关键词和数字，完整的话靠口播。样图每张卡片只有 2 行字。
3. **截图要清晰** —— 演示截图是你的证据，模糊/变形会显得不专业。统一 1440×900 截图，加窗口框。
4. **数据要大** —— 幻觉率 <5%、286 测试、78 知识点，这些是你的王牌，用大字讲。
5. **审核 Agent 要突出** —— 它是你和"假多智能体"的分水岭，视觉上要一眼看到（金色）。

## 第 4 页 · 创新点 1：真实的多智能体协同（不是"多个提示词"）

**页面要点**
- 六类 Agent，各司其职、真实协作：
  - **诊断 Agent** → 读懂你是谁
  - **规划 Agent** → 规划学什么、什么顺序
  - **检索 Agent** → RAG 找到可靠依据
  - **生成 Agent** → 产出多模态资源
  - **审核 Agent（Critic）** → 逐句核查，拦截幻觉
  - **决策 Agent** → 不合格就重试/降级
- 关键：**审核 Agent 有否决权**，不合格的内容进不了用户界面

**配图**：多智能体工作流图（架构图，或系统里的工作流审核界面截图）

**口播**
> "很多项目说自己是多智能体，其实是几个提示词轮流跑。我们的六个 Agent 是有真实分工和**否决权**的——特别是审核 Agent，它会逐句检查生成的内容有没有依据，不合格的内容会被打回重试，根本到不了用户面前。这是我们和'看起来像多智能体'的本质区别。"

**回答评委**：你的多智能体是真的吗？

## 第 7 页 · 创新点 4：可信 AI —— 我们敢让 AI 被检查

**页面要点**
- **逐句接地（Grounding）**：每句话都要能追溯到检索到的依据
- **审核 Agent 逐句核查** + 不合格重试
- **内容安全拦截**
- 硬指标：**幻觉率 < 5%**（实测 0.0428）
- 学生看到的每句话，都可以点开看它的出处

**配图**：讲义带引用上标的截图（`learning-flow.png` 里有）+ 溯源展开截图

**口播**
> "AI 教育最大的风险是——它讲错了，学生还当真。所以我们做了逐句接地：每一句话都必须有检索到的依据支撑，审核 Agent 会逐句核查，不合格就打回重试。我们的幻觉率实测低于 5%。学生看到的每一句话，都能点开看出处。**我们敢让 AI 被检查。**"

**回答评委**：AI 生成的内容可信吗？（**这是 AI 教育最要害的问题，一定要讲**）

## 第 8 页 · 创新点 5：懂科学的学习方法论

**页面要点**
- 我们不只是"生成资料"，而是**用教育学方法教你学**：
  - **苏格拉底式导学** —— 不给答案，一步步问到你自己想通
  - **费曼讲解** —— 你讲给 AI 听，AI 找出你没讲清的地方
  - **康奈尔笔记** —— 结构化记录
  - **掌握式学习** —— ≥70 分才进阶，不留夹生饭
  - **间隔重复** —— 对抗遗忘曲线
- 理论支撑：建构主义 / ZPD / 布鲁姆两西格玛 / 艾宾浩斯

**配图**：苏格拉底导学对话截图 + 费曼讲解评估截图（展示"你讲了卷积核，但漏了池化层"）

**口播**
> "这是我们和纯技术项目最大的不同——我们真的懂教育。苏格拉底导学不直接给答案，而是一步步问，直到学生自己想通；费曼讲解让学生讲给 AI 听，AI 会找出他没讲清的地方。这些都不是我们拍脑袋想的，背后是建构主义、最近发展区、掌握式学习这些成熟的教育理论。"

## 第 11 页 · 核心算法

**页面要点**
- **CPDP（能力-偏好双驱动路径规划）**
  - 能力向量 → 选节点、定顺序（拓扑排序 + 先修依赖）
  - 偏好向量 → 定每个节点的资源形态
- **GCG（接地一致性守卫）**
  - 每句生成内容与检索证据做语义比对
  - 相似度 ≥ 阈值（0.6，实测标定）判定为"已接地"
  - 未接地 → 审核 Agent 打回重试
- **RRF 混合检索**：向量 0.7 + BM25 0.3，k=60

**配图**：算法公式 + 流程图

**口播**
> "两个核心算法。CPDP 用能力向量决定学什么、用偏好向量决定怎么学。GCG 是我们的防幻觉守卫——每句生成的话都要和检索证据比对，语义相似度达不到阈值就打回重试。这个阈值 0.6 不是拍脑袋的，是我们用真实数据标定出来的。"

# 🎤 答辩必被问的 5 个问题（提前准备）

1. **"你的多智能体是真协同还是几个提示词？"**
   → 讲审核 Agent 的**否决权**、工作流的重试/降级决策、LangGraph 的状态流转。

   → 诚实说明：critic 会打回重试，重试后的内容可能引入新的表述；且两组样本量/批次有差异。**关键：critic 的价值不只是降幻觉率，更是拦截不合格内容（安全性、完整性）**。别硬圆，坦诚 + 解释设计意图。

3. **"78 个知识点的内容质量怎么保证？非核心点是 AI 生成的吗？"**
   → 诚实：6 个核心点手工精修，其余走参数化模板 + RAG 接地 + 审核。**明示"通用模板"，不假装定制**（我们代码里就是这么标注的，很坦荡）。

4. **"防幻觉的阈值 0.6 是怎么定的？"**
   → 讲标定过程：bge 实测中位数 0.73，0.75 会误判 62% 的已接地句子，最终标定 0.6。**这是科学标定，不是拍脑袋**。
