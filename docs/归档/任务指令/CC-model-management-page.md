# 角色
资深全栈工程师。项目已联调，禁改既有接口签名。本会话做独立的模型管理页。

# 背景
现在魔搭 key 走后端 .env、前端只能选模型，不直观、不好扩展。要做成可在界面管理多个模型（含 key）的独立页。魔搭推理 API 兼容 OpenAI 格式（base_url=https://api-inference.modelscope.cn/v1）。后端已有 LLMClient 适配层（mock/deepseek/魔搭 provider）。

# 任务

## 1. 左侧工具栏加"模型管理"入口 + 独立页面
- 放在侧栏"工具"分组；独立页面。

## 2. 模型管理页功能
- **列出已配置模型**：deepseek（内置默认）+ 用户已添加的魔搭等，显示 显示名/provider/model_id/状态（当前使用/可用）；
- **添加模型**：界面填写 显示名 + provider类型（openai兼容/魔搭/deepseek）+ base_url + model_id + api_key。魔搭填 base_url=https://api-inference.modelscope.cn/v1 + 魔搭key + 模型id 即可；
- **切换当前使用模型**：一键设为当前，后续生成走该模型；
- **测试连通性**：填完/选中后可点"测试"，后端用该配置调一次轻量请求，返回成功/失败，让用户确认可用；
- **编辑/删除**已添加的模型配置。

## 3. key 安全（重点·为产品化打底）
- api_key **加密存储**（不明文进 DB——用对称加密如 Fernet + 服务端密钥，或等效方案）；
- 前端提交后**不在前端任何地方留存**（不进 localStorage、不持久化到前端 state）；
- 返回前端时 key **一律脱敏**（只回显后四位，如 ****abcd）；
- key **不出现在任何日志 / 错误信息**里；
- **按 user 隔离**：每个用户只能查看/管理/使用自己配置的模型与 key。

## 4. 稳健与兜底
- 保留 deepseek 为内置默认（不配任何 key 时用它/或 mock）；**默认行为不变**（当前模型默认=deepseek）；
- 某模型调用失败/超时 → 优雅降级（回落默认模型或 mock），**绝不崩**；
- mock 兜底：无任何 key 全链路可跑。

## 5. 接口
- 新增模型配置 CRUD 接口（增/删/改/查/切换/测试连通）——套统一信封、追加接口文档、key 脱敏返回、按 user 校验归属；
- **不改既有生成接口签名**（当前模型为新增配置，向后兼容）。
