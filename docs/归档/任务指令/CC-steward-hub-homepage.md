# 角色
资深前端工程师。禁改既有接口签名。本会话把学情管家做成产品的中枢首页。

# 目标
用户进入即见管家首页，一眼看懂"AI 管家在统筹我的整个学习"，并有清晰入口进入各功能。把散在各处的能力串成一个连贯闭环故事。

# 任务

## 1. 学情管家置顶为侧栏第一项 / 中枢首页
- 学情管家放侧栏最上方（统领位），作为登录后默认落地的中枢首页（若已置顶则确认）。

## 2. 中枢首页闭环结构（把珍珠串成项链）
按"需求推测 → 规划 → 监测 → 建议"的连贯叙事组织，全部复用现有数据：
- **① 我对你的理解（需求推测·来自画像）**：展示管家推测的学习需求/目标/薄弱点/画像概要（读现有画像/诊断结果）——"我推测你想学 X、当前在 Y 较薄弱"。
- **② 为你规划的路径（来自 planner + 时间线）**：展示当前学习路径概要 + 时间线（预计周期/总时长/进度%/下一步）——复用会话三的路径+时间线数据。带"继续学习"入口。
- **③ 学习监测（来自掌握度 + 各Agent活动）**：掌握度/进度概览 + 各专家 Agent 活动看板（诊断/规划/生成/评估/文档学习，复用现有真实数据）——"管家在监测你的全过程"。
- **④ 管家建议（主动建议）**：基于监测的主动学习建议（复用现有建议逻辑）——"建议你下一步做 X"。
- 四部分形成从"理解你→为你规划→看你进展→给你建议"的连贯闭环，体现管家统筹全局。

## 3. 全功能入口（合理的导航）
- 中枢首页提供清晰的功能入口，让用户看懂整个软件有什么、从哪进：
  核心学习（画像诊断/学习路径/学习资源）、文档学习、我的资源库、知识图谱、Agent工作流、即时辅导。
- 入口按逻辑组织（如按"学习流程"或"功能类型"），不是乱堆；每个入口一句话说明用途。

## 4. 全局返回管家
- 各功能页顶部加"← 学情管家"返回入口，随时回到中枢首页。
- 可选：简单的层级指示（当前在哪个功能），让导航有方向感。

# 约束
- 纯展示层 + 导航：复用现有画像/路径/时间线/掌握度/建议/Agent活动/知识图谱等数据与接口，不新造能力、不改内置逻辑与既有接口签名（新增仅追加）；
- 数据真实（画像/路径/进度/建议/Agent活动都来自现有真实数据，不写死假值）；
- 套现有设计令牌、深浅主题正常、响应式合理；mock 兜底。

# 验证（截图）
1. 学情管家为侧栏首项 / 中枢首页；进入即见闭环四部分（理解你→规划→监测→建议）；
2. 四部分数据真实（画像/路径+时间线/掌握度/Agent活动/建议都来自现有能力，非写死）；
3. 全功能入口清晰、逻辑合理、可进入各功能；
4. 各功能页有"←学情管家"返回、能回中枢；
5. 深浅主题正常、响应式合理、tsc 干净、0 console error、既有功能无回归。

# 输出
现状 + 中枢首页设计说明（各部分数据来源）+ 改动文件清单 + 接口文档增量（如有）+ 验证结果 + 红线自检。完成即停。
