资深全栈工程师。视频服务端渲染能力已实现可用，本会话只修"命中率/可见性"，不重做渲染。

4. 既有链路无回归、tsc 干净、0 console error。

# 角色
资深全栈工程师。本会话从零建"我的资源库"。禁改既有接口签名（新增追加）。

# 任务
1. **数据层**：新建 GenerationLog 表（id, user_id, kp_id, kind, difficulty, title, resource_ref, created_at）；在讲义/视频/图解/思维导图/代码各生成处**追加写入一行带 user_id 的记录**（不改既有生成逻辑，只追加埋点）。
