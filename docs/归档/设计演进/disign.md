你现在是一位资深前端开发工程师。请帮我重构和优化当前提供的学情概览仪表盘组件代码。我们将基于高级UI交互规范，对视觉层级、色彩对比度以及 ECharts 配置进行细节打磨。项目使用 React + TailwindCSS。



\# 具体修改指令（请逐项执行代码修改）：



\## 1. 顶部数据卡片优化 (Visual Hierarchy)

\- \*\*强化盲区警示\*\*：找到“知识盲区”这个数据卡片，将其背景色或边框改为带有微弱警示感的色调（如 `bg-orange-50/50 border border-orange-100`），图标颜色同步调整，使其在四个均等卡片中脱颖而出。

\- \*\*重构综合能力分\*\*：找到右上角“72.5 综合能力分”的卡片，\*\*去掉其现有的白色卡片背景和阴影\*\*。将其与左侧的欢迎语（“您的AI学习旅程已开启...”）进行 Flex 布局排版融合。适当放大环形进度图的尺寸，使其成为该区域的视觉焦点。



\## 2. ECharts 雷达图配置优化 (Data Visualization)

\- \*\*增加体积感\*\*：在雷达图的 `series` 配置中，为数据多边形增加内部填充色。请添加 `areaStyle` 属性，设置与描边色同色系但带有 15%-20% 透明度的填充（例如 `color: 'rgba(54, 162, 235, 0.2)'`）。

\- \*\*标签间距调整\*\*：调整 `radar.axisName` 的配置，统一雷达图外围文字与顶点的间距，确保排版规整不拥挤。



\## 3. 侧边栏与文字对比度 (Accessibility)

\- \*\*加深未选中文字\*\*：侧边栏未选中项的文字颜色过浅，请将 Tailwind 类从类似 `text-gray-400` 加深至 `text-gray-600` 或 `text-slate-500`，提升阅读性。

\- \*\*优化选中指示器\*\*：选中状态（“学情概览”）左侧的蓝色高亮实线略显生硬，请将其宽度改细（如 `w-1` 改为 `w-\[3px]`），并增加完全圆角 `rounded-full`。



\## 4. 标签与空间排版 (Spacing \& Badges)

\- \*\*高对比度标签\*\*：“能力分析”卡片中的绿色和黄色能力标签底色与文字对比度不足。请统一修改为“浅色背景 + 深色文字”的规范。例如：优势领域使用 `bg-emerald-50 text-emerald-700`，待提升领域使用 `bg-amber-50 text-amber-700`。

\- \*\*收紧内部间距\*\*：缩小“能力分析”卡片内部菱形图标与标签之间的垂直/水平间距（调整相关的 `gap` 或 `margin` 类），让同类信息的分组更加紧凑，留出更多的外部呼吸空间。
