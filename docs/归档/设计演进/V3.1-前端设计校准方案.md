### 三个关键发现
1. **方向性偏差（待校准）**：`globals.css` V3.0 把背景灰化为 `#eef2f7` + 双向软阴影（`--shadow-raised`），实机偏灰、偏「黏土感」，与 goal.png 的「轻盈 / 空气感 / 发光」相悖。**决议：回归 goal.png 的玻璃发光路线（见 P1）。**
2. **字体完全失效（已修，见 P0）**：`index.html` 加载 Plus Jakarta Sans，CSS 却引用未加载的 `Inter`，且 Google Fonts CDN 在本环境 `ERR_CONNECTION_CLOSED` → 全站回退系统字体。
3. **技术栈与文档不符**：disign.md 写 TailwindCSS，实际是纯 CSS 变量 + 组件 CSS。后续指令以 **CSS 变量** 为准，不引入 Tailwind。

## 二、P0 — 字体系统修复 ✅ 已完成（2026-05-31）

**策略**：放弃被墙的 Google Fonts CDN，改为 **自托管 woff2**；CJK 用系统高质量黑体栈（Noto SC webfont 体积 75MB 且 fontsource 子集不全，不自托管）。

- **拉丁标题/展示**：**Sora Variable**（几何科技感，规避 skill 点名的「AI 通病字体」Inter）
- **数据/指标/数字**：**JetBrains Mono**（72.5 / 65% / 23:15 等更精密）
- **中文**：`'PingFang SC','HarmonyOS Sans SC','Source Han Sans SC','Noto Sans SC','Microsoft YaHei'`

**改动文件**：
| 文件 | 改动 |
|------|------|
| `scripts/build-fonts.mjs`（新增） | 把 `@fontsource` 的 woff2 拷到 `public/fonts/`，生成绝对路径 `fonts.css` |
| `public/fonts/*.woff2`（新增 14 个） | Sora 2 + JetBrains Mono 12，自托管 |
| `src/styles/fonts.css`（新增，自动生成） | `@font-face`，`url(/fonts/...)` 绝对路径 |
| `src/main.tsx` | 改 `import './styles/fonts.css'`（替换失效的 @fontsource JS import） |
| `src/styles/globals.css` | `--font-sans/display/mono` 改用 Sora + JetBrains + 系统 CJK 栈 |
| `index.html` | 删除失效的 Google Fonts `<link>` |

> **为何不直接 `import '@fontsource/...'`**：Vite dev 不重写 @fontsource CSS 内的相对 `url(./files/...)`，浏览器按文档根请求 `/files/*.woff2` → 命中 SPA 回退拿到 `index.html` → `OTS parsing error`。改走 `public/` 绝对路径彻底规避。

**验证**：`document.fonts.check` → Sora ✅ / JetBrains ✅，0 解码错误；实机 72.5 / 23:15 / 65% 已呈现 Sora/Mono 字形。

> 后续若要更具个性的中文字（如 MiSans / 鸿蒙），可在联网时下载 woff2 子集放入 `public/fonts/` 并加 `@font-face`，再把 `--font-cjk` 首位替换即可，不影响现有结构。

## 三、P1 — 视觉语言校准（玻璃发光路线）✅ 已完成（2026-06-01）

**目标气质**：轻盈 + 空气感 + 发光（Apple / Linear / Vercel / VisionOS）。保留 V3.0 中好的发光与脉冲，把「灰底 + 双向软阴影（神拟态）」换回「近白 + 玻璃 + 单向投影 + 顶部高光 + 蓝紫光晕」。

**实际改动文件（5 个，符合 disign.md ≤5）**：
| 文件 | 改动 |
|------|------|
| `src/styles/globals.css` | 背景令牌→近白；阴影令牌（raised/soft/float/glass/pressed…）双向神拟态软阴影→单向玻璃投影+顶部高光 |
| `src/styles/App.css` | 三枚光晕球强度上调（蓝 .07→.12 / 紫 .04→.07 / 绿 .03→.05），更明显的发光 |
| `src/pages/Dashboard.css` | 15 处硬编码神拟态阴影（header/stat-card/盲区警示/图标/card/标签/面板）→玻璃投影；hover 加蓝色光晕 |
| `src/components/LearningPathCard.css` | 9 处（卡片/完成/进行中/脉冲/节点/徽章/按钮三态）→玻璃投影 |
| `src/components/AgentStatusCard.css` | 3 处（卡片默认/hover/状态徽章）→玻璃投影 + hover 蓝光晕 |

> 注：原计划仅 globals/App 两文件，但 Dashboard/LearningPathCard/AgentStatusCard 内存在**硬编码**的神拟态灰阴影 `rgba(163,177,198,…)`（共 27 处），纯令牌切换无法覆盖，故一并转换以保证全站玻璃质感一致。已用 grep 确认全 `src/` 无残留 `163,177,198`。

**验证**：实机 Dashboard 截图 — 卡片改为干净玻璃投影（去黏土灰边），背景近白+蓝紫光晕，3D 立方体处紫色光晕；0 控制台错误。

```css
/* globals.css —— 背景回近白空气感 */
--bg-page-start:#f8fbff; --bg-page-mid:#eef4ff; --bg-page-end:#f7faff;
--bg-card: rgba(255,255,255,0.72);
--bg-card-hover: rgba(255,255,255,0.85);

/* 卡片：玻璃 + 轻发光（替换 --shadow-raised 神拟态）*/
.card{
  background:var(--bg-card);
  backdrop-filter:blur(24px); -webkit-backdrop-filter:blur(24px);
  border:1px solid rgba(255,255,255,0.45);
  box-shadow:0 8px 32px rgba(15,23,42,0.06);
}
.card:hover{
  transform:translateY(-4px);
  box-shadow:0 16px 40px rgba(0,0,0,0.10), 0 0 24px rgba(37,99,235,0.12);
}

/* App.css —— 三枚动态光晕球（蓝/紫/绿）回归 */
.app__gradient-orb--1{ background:radial-gradient(circle, rgba(12,131,247,0.15), transparent 70%); }
.app__gradient-orb--2{ background:radial-gradient(circle, rgba(124,58,237,0.08), transparent 70%); animation-delay:-7s; }
.app__gradient-orb--3{ background:radial-gradient(circle, rgba(16,185,129,0.06), transparent 70%); animation-delay:-14s; }
```

**改动文件（≤2）**：`globals.css`、`App.css`。

## 四、统一设计令牌（规范）

```
圆角   16px 卡片 / 12px 小件 / 9999px chip·徽章
过渡   fast 200ms / normal 300ms / slow 500ms，cubic-bezier(0.4,0,0.2,1)
进场   opacity 0→1 + y16→0，staggerChildren 0.08s（Framer Motion，统一到全部页面）

       绿 …rgba(16,185,129…)  紫 0 0 16px rgba(124,58,237,.4)

```
