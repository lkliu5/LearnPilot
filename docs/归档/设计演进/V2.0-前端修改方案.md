## 一、设计诊断与升级方向

### 1.1 当前问题

| 模块 | 当前状态 | 问题描述 |
|------|---------|---------|
| 整体气质 | 传统后台风格 | 像企业ERP，缺乏科技感和未来感 |
| 背景 | 纯灰/纯白 | 无层次，无空间感，"死白" |
| Sidebar | 普通深色 | 太实、太黑、无发光、无呼吸感 |
| 数据卡片 | 普通白卡片 | 无趋势图、无发光、无动画 |
| 雷达图 | 基础ECharts | 无发光、无渐变、标签遮挡 |
| 能力分析 | 简单标签 | 无3D视觉锚点，对比度不足 |
| 学习路径 | 平铺卡片 | 无路径连接线、无流动动画 |
| Agent状态 | 静态列表 | 无脉冲、无呼吸、无实时感 |
| 动画系统 | 几乎无 | 缺少页面进入、卡片stagger、数字增长动画 |

### 1.2 目标气质

```
轻盈 + 高级 + 空气感 + 空间层次 + 未来科技感
参考: Apple + Linear + Vercel + VisionOS
```

```tsx
const containerVariants = {

<motion.div

  initial="hidden"
  animate="visible"
```

## 七、视觉规范总结

### Glassmorphism 玻璃效果标准

```css
background: rgba(255, 255, 255, 0.6~0.7);
backdrop-filter: blur(20~24px);
-webkit-backdrop-filter: blur(20~24px);
border: 1px solid rgba(255, 255, 255, 0.4~0.5);
box-shadow: 0 2px 12px rgba(0, 0, 0, 0.06);
```

### 发光效果标准

```css
/* 蓝色发光 */
box-shadow: 0 0 8px rgba(37, 99, 235, 0.6), 0 0 16px rgba(37, 99, 235, 0.3);

/* 绿色发光 */
box-shadow: 0 0 8px rgba(16, 185, 129, 0.6), 0 0 16px rgba(16, 185, 129, 0.3);

/* 紫色发光 */
box-shadow: 0 0 16px rgba(124, 58, 237, 0.4);
```

### Hover 交互标准

```css
transform: translateY(-2~4px);
box-shadow: 0 16px 40px rgba(0, 0, 0, 0.12), 0 0 20px rgba(37, 99, 235, 0.1~0.15);
```

# 1. 无限读取文件

同一文件：

禁止重复读取超过3次。

---

# 2. 全局扫描项目

除非明确要求。

否则：

不要：

* 分析整个 src
* 遍历全部组件
* 检查所有依赖

---

# 3. 修改业务逻辑

当前阶段：

仅允许：

# UI/UX 重构

禁止：

* 修改 API
* 修改 Zustand
* 修改 Router
* 修改数据结构
* 修改业务状态流

---

# 4. 自由发挥 UI 风格

必须：

# 严格贴近原型图

不是：

“AI 自己设计”。

---

# 四、每阶段输出要求

每完成一个阶段：

必须输出：

## 1. 修改文件列表

例如：

```txt
- Dashboard.tsx
- Sidebar.tsx
- RadarChart.tsx
- dashboard.css
```

---

## 2. 已实现效果

例如：

```txt
- glass card
- hover motion
- glow radar chart
```

---

## 3. 未完成部分

例如：

```txt
- Agent pulse animation
- path flow effect
```

---

## 4. 下一阶段建议

例如：

```txt

重构 LearningPath 模块
```

# 五、视觉优先级规则（非常重要）

开发时：

优先级：

# 原型图 > 文档描述 > AI理解

即：

如果：

代码效果与原型图不一致。

以：

# 原型图为准。

---

# 六、UI还原度要求

最终目标：

# 90%+ 视觉接近度

包括：

* 布局
* 间距
* 光感
* hover
* 动画
* 卡片层级
* 发光效果
* 留白

不是：

仅实现：

“类似”。

---

# 七、动画规则

动画必须：

```txt
轻
柔
慢
克制
高级
```

禁止：

```txt
廉价炫酷动画
过快动画
大幅缩放
夸张弹跳
```

---

# 八、技术规则

必须优先使用：

* TailwindCSS
* Framer Motion
* CSS Variables

避免：

* 大量 inline style
* 重复 CSS
* 硬编码颜色
* 大面积 !important

---

# 九、组件规范

所有视觉组件：

必须：

* 可复用
* 可扩展
* 风格统一

统一：

* 圆角
* 阴影
* hover
* transition
* glow

---

# High Fidelity UI Reconstruction

# AI Learning Operating System
