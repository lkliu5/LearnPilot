## 一、项目概述

### 1.1 项目定位
本项目为"软件杯"赛题——**领域知识个性化资源生成和多智能体系统开发**的前端可视化交互系统。

### 1.2 设计理念
根据需求文档要求，前端界面采用"**轻盈、直观、高效**"的设计风格：
- **轻盈**：毛玻璃效果(Glass Morphism)、柔和渐变背景、轻量阴影
- **直观**：清晰的信息层级、即时状态反馈、可视化图表
- **高效**：平滑动画过渡、响应式布局、快速导航

## 三、已完成功能模块

### 3.1 设计系统 (globals.css)

**CSS变量定义**：
- 主色调：`--primary-*`（柔和蓝色系 #0c83f7）
- 强调色：`--accent-*`（暖珊瑚色）
- 成功色：`--success-*`（柔和绿色）
- 中性色：`--gray-*`（10级灰度）
- 间距：`--space-xs` 到 `--space-3xl`
- 圆角：`--radius-sm` 到 `--radius-full`
- 过渡：`--transition-fast/base/slow`

**通用组件样式**：
- `.glass-card` - 毛玻璃卡片效果
- `.agent-status--*` - Agent状态指示器
- `.difficulty-badge--*` - 难度等级徽章（入门→精通5级）
- `.progress-bar` - 进度条组件
- `.skeleton` - 加载骨架屏

### 3.2 侧边栏导航 (Sidebar)

**功能特性**：
- 4个导航项：学情概览、画像构建、学习路径、Agent调度
- 可折叠/展开（宽度260px→80px）
- 底部用户信息区
- 动态选中状态指示器

### 3.3 学情概览首页 (Dashboard)

**核心组件**：
- 综合能力评分圆环（SVG动画）
- 4个统计卡片：知识覆盖率、优势知识点、知识盲区、已学资源
- ECharts雷达图：6维知识掌握度可视化
- 能力分析区：优势/待提升领域标签
- 学习路径预览（横向滚动）
- Agent状态列表

### 3.4 学习画像构建 (ProfileBuilder)

**多步表单流程**：
1. **基本信息**：学历背景、专业方向、学习目标（单选按钮组）
2. **知识自评**：12个AI知识点卡片选择，滑块调节掌握度（0-100）
3. **AI分析动画**：脉动光球动画，模拟Agent处理过程
4. **诊断结果**：综合等级、评分、优势知识点、推荐路径

**知识点列表**：
- 机器学习基础(入门) → 神经网络(初级) → 深度学习(中级)
- CNN/RNN/注意力机制(中级) → Transformer(高级)
- BERT/GPT(高级) → 大模型微调(精通) → Prompt工程(初级)
- RAG/AI Agent(中级/高级)

### 3.5 学习路径页面 (LearningPath)

**双视图模式**：
- **时间线视图**：垂直时间轴、状态标记、进度条、里程碑侧栏
- **卡片视图**：横向滚动卡片，LearningPathCard组件

**状态系统**：
- 已完成：绿色标记、勾选图标
- 进行中：蓝色脉动、进度百分比
- 待学习：灰色标记

### 3.6 Agent协同调度大屏 (AgentWorkflow)

**核心可视化**：
- 中央编排器节点（LangGraph）
- 3个Agent节点：学情诊断、领域知识生成、内容审核
- RAG知识库节点
- 网络连接线SVG

**交互演示**：
- "启动演示"按钮触发模拟工作流
- 4阶段进度指示器：诊断→生成→审核→完成
- Agent状态卡片动态更新
- 消息日志实时记录
- 统计面板：完成Agent数、消息交互数、工作流进度

## 四、关键代码实现

### 4.1 背景渐变动画 (App.css)

```css
.app__gradient-orb--1 {
  width: 600px;
  height: 600px;
  background: radial-gradient(circle, rgba(12, 131, 247, 0.15), transparent 70%);
  animation: orb-float 20s ease-in-out infinite;
}

@keyframes orb-float {
  0%, 100% { transform: translate(0, 0) scale(1); }
  25% { transform: translate(30px, -30px) scale(1.05); }
  50% { transform: translate(0, 20px) scale(1); }
  75% { transform: translate(-20px, -10px) scale(0.95); }
}
```

### 4.2 页面过渡动画 (App.tsx)

```tsx
<AnimatePresence mode="wait">
  <motion.div
    key={currentPage}
    initial={{ opacity: 0, y: 20 }}
    animate={{ opacity: 1, y: 0 }}
    exit={{ opacity: 0, y: -20 }}
    transition={{ duration: 0.3, ease: 'easeInOut' }}
  >
    {renderPage()}
  </motion.div>
</AnimatePresence>
```

### 4.3 Agent节点脉动效果 (AgentWorkflow.css)

```tsx
// 运行中的Agent节点会显示脉动光晕
animate={isActive ? {
  boxShadow: [
    '0 0 0 0 rgba(99, 102, 241, 0)',
    '0 0 20px 10px rgba(99, 102, 241, 0.3)',
    '0 0 0 0 rgba(99, 102, 241, 0)'
  ]
} : {}}
transition={{ duration: 1.5, repeat: Infinity }}
```

## 五、运行与部署

### 5.1 开发环境启动

```bash
cd F:\软件杯\frontend
npm install          # 安装依赖（已完成）
npm run dev          # 启动开发服务器
```

**当前运行地址**：http://localhost:3001

### 5.2 构建生产版本

```bash
npm run build        # TypeScript编译 + Vite构建
npm run preview      # 预览生产构建
```

### 5.3 API代理配置 (vite.config.ts)

```ts
server: {
  port: 3000,
  proxy: {
    '/api': {
      target: 'http://localhost:8000',
      changeOrigin: true
    },
    '/ws': {
      target: 'ws://localhost:8000',
      ws: true
    }
  }
}
```

后端服务启动后，前端会自动代理API请求到8000端口。

## 八、问题记录与解决方案

### 8.1 已解决问题

| 问题 | 解决方案 |
|------|----------|
| `react-flow-renderer` 包不存在 | 从package.json移除，项目未使用 |
| `tsconfig.node.json` 缺失 | 创建Vite专用TS配置文件 |

### 8.2 注意事项
- Framer Motion需要React 18+支持
- ECharts初始化需要在DOM挂载后执行
- CSS变量在globals.css中统一定义，各组件直接引用
