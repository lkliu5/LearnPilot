# 智学中枢｜6 分钟演示视频脚本（初学者视角）

> 实测环境：`http://localhost:3000/`  
> 演示账号：`learner_001 / 123456`  
> 建议成片：5:50–6:05，1080p，16:9，鼠标操作真实可见。

## 一、演示叙事

不要按菜单逐项介绍。全片只讲一个故事：

> “我是一个想系统学习 AI、但不知道从哪开始的初学者。系统先了解我，再给我一条可解释的路径；学习内容由多个 Agent 基于可信资料生成并审核；我用费曼、康奈尔和测试真正学会，卡住时还能即时求助，也能上传自己的资料继续学习。”

核心创新点随用户旅程自然出现：

1. 行为实测画像：能力决定“学什么”，偏好决定“怎么学”。
2. 可解释的个性化路径：薄弱点前置、已掌握内容后置。
3. LangGraph 多智能体真实协同：诊断、RAG 检索、生成、审核、决策。
4. 可信生成：逐句接地、审核重试、幻觉率与来源可查。
5. 学习方法工程化：康奈尔、费曼、苏格拉底、掌握式测试形成闭环。
6. 基于个人文档的学习：文档问答可溯源，并生成六类资源。

## 二、正式录制脚本

### 0:00–0:25｜开场：我需要的不是一堆课程

**画面**

- 打开欢迎页，停留在主视觉。
- 鼠标缓慢移过“多智能体驱动 · 防幻觉可溯源 · 懂科学学习方法”。
- 点击“开始个性化学习”。

**旁白**

> 我刚开始系统学习人工智能，最大的问题不是没有资料，而是不知道自己该从哪里开始，也无法判断 AI 生成的内容是否可信。智学中枢不是再给我一堆课程，而是让 AI 先读懂我，再为我规划、生成、辅导和评估。

### 0:25–0:50｜登录：进入我的 AI 学习空间

**操作**

- 输入 `learner_001`、`123456`，点击“进入系统”。
- 登录后在学情管家首页停留 3 秒。
- 鼠标依次指向综合能力、知识点掌握、图谱覆盖和 Agent 活动。

**旁白**

> 登录后，我首先看到的不是课程商城，而是一位持续工作的 AI 学情管家。它把画像、路径、掌握度、资源和各个 Agent 的活动汇总在一起，并告诉我当前最值得做的下一步。

### 0:50–1:25｜创新一：不是填表，而是用行为建立画像

**操作**

- 点击左侧“画像诊断”。
- 在三种入口上依次停留：做题式诊断、自述、直接跳过。
- 最后把鼠标停在“实测 · 高置信”和“能力靠微测行为反推”上。
- 不要正式做完整诊断，避免占用 2–3 分钟。

**旁白**

> 作为初学者，我可以做一段边聊边测的诊断。系统不只问“你觉得自己会多少”，而是通过微测行为反推真实能力，再把能力、偏好和学习目标分开建模。实测结果标记为高置信，自述只有中置信；不确定的信息不会被 AI 编造。

### 1:25–2:00｜创新二：一人一路径，而且能解释原因

**操作**

- 点击左侧“学习路径”。
- 在顶部规划理由、预计 2 周、12 个知识点处停留。
- 鼠标指向“CNN 架构”与“Transformer 架构”的薄弱点说明。
- 再指向“机器学习基础”“神经网络基础”的“已掌握、后置复习”说明。
- 轻微下滚，展示时间线的层次感，不要滚到底。

**旁白**

> 规划 Agent 会把画像和真实掌握度一起用于排序。我的 CNN 和 Transformer 微测较弱，所以被前置集中攻克；已经通过测试的基础知识则被后置快速复习。这里不仅给出顺序，还解释为什么这样规划，并估算每一步和全程的学习时间。

### 2:00–3:05｜创新三：按需生成，而不是一次堆满

**操作**

- 点击左侧“学习资源”。
- 先停在“有序学习”和“资源中枢”两个入口。
- 指向六类资源卡片和顶部“已校验 · 幻觉率 <5%”。
- 点击“定制讲义”。
- 在讲义弹窗中依次展示：
  - 难度自适应档位；
  - 正文中的公式、图解和引用角标；
  - 快速滚到“参考文献”，停在来源名称、段落与可信度上。

**旁白**

> 进入当前知识点后，系统不会把所有内容一次性灌给我，而是按需生成讲义、视频、导图、图解、代码和外部资源。讲义会根据我的水平调整难度，正文包含公式、图示和逐条引用；每条来源都能追溯到具体教材、段落和可信度。

### 3:05–3:55｜创新四：真实多智能体与审核回环

**推荐画面方案**

- 使用已经预录好的真实工作流片段，或从讲义点击“查看生成过程”回放完成态。
- 画面至少出现：
  - 学情诊断 Agent 完成；
  - RAG 检索到知识切片；
  - 领域知识生成 Agent 提交草稿；
  - 内容审核 Agent 显示未达阈值并发起重试；
  - 最终通过或降级终态。

**当前实测可用素材**

- 主题：CNN 架构，初级。
- 第一次审核：`0.6842 < 0.8`，发起第 1 次重试。
- 第二次审核：`0.7901 < 0.8`，发起第 2 次重试。
- RAG 实测检索到 6 条相关知识切片。

**旁白**

> 这份内容不是单次调用大模型直接输出。后台由 LangGraph 编排多个专家 Agent：先诊断我的学情，再通过 RAG 检索可信资料，生成 Agent 编写内容，审核 Agent 做接地校验。刚才两次评分都没有达到 0.8，系统真实地打回重写；它宁可重试或降级，也不把不可靠内容直接交给我。

### 3:55–4:35｜创新五：把科学学习方法做进流程

**操作**

- 回到“学习资源”，点击“有序学习”。
- 快速展示步骤条：视频/讲义/图解 → 康奈尔笔记 → 费曼讲解 → 代码实操 → 阶段测试。
- 打开康奈尔笔记，指向线索、笔记、总结三区。
- 切到费曼讲解，展示“用自己的话讲给 AI”。
- 最后停在阶段测试与“70 分达标才推进”的提示。

**旁白**

> 系统的目标不是让我“看过”，而是让我真正学会。它把康奈尔笔记、费曼讲解、代码实操和阶段测试编排成有序流程。我需要整理、复述、实践，再用测试验证；达到 70 分才算掌握。卡住时还能随时呼出苏格拉底式导师，它不会直接塞答案，而是通过追问引导我自己想通。

### 4:35–5:05｜创新六：即时辅导，卡住就问并按需补资源

**操作**

- 在学习资源页点击右下角常驻的“即时辅导”。
- 输入一个初学者真实会问的问题：
  - `我还是不理解卷积核为什么可以识别不同特征，能用生活中的例子引导我吗？`
- 展示 AI 的流式回复，重点停在它的追问而不是最终答案。
- 点击“针对性生成资源”或“我没懂”，展示系统识别知识缺口后给出的资源清单。
- 勾选“图解”与“入门讲义”，展示按当前问题生成资源的状态；正式录制前应预热结果。
- 如果学习正文支持“选中即问”，可补一个 2 秒镜头：选中“权重共享”后出现提问浮泡。

**旁白**

> 如果我在学习中卡住，不需要离开当前页面重新描述上下文。即时辅导常驻在学习现场，也支持选中文字直接提问。它先用苏格拉底式追问帮我定位到底哪里没想通；仍然不理解时，系统会根据当前知识缺口生成一份针对性资源清单，例如更入门的讲义和专门的图解。这不是通用聊天，而是基于画像、当前知识点和学习行为的实时反馈。

### 5:05–5:35｜创新七：用我自己的资料学习

**操作**

- 点击左侧“文档学习”。
- 展示三栏工作台：
  - 左侧已有文档、分块数量和概览；
  - 中间“和文档对话”及“严格基于文档、标注出处”；
  - 右侧六类资源生成。
- 点击一个已预热的问题，例如“核心概念/定理有哪些？”。
- 展示已生成答案及出处；录制前必须先预热，避免现场等待。

**旁白**

> 如果我有自己的讲义、论文或课件，也可以上传到独立的文档空间。系统只基于所选文档回答，并标注原文出处；同一批资料还能生成讲义、视频、图解、导图、练习题和记忆闪卡。个性化学习因此不再局限于平台预置课程。

### 5:35–6:00｜收尾：从一节课回到完整知识体系

**操作**

- 点击“知识图谱”。
- 在 78 个知识点、7 大板块处停留。
- 点击“AI Agent 智能体”展开板块。
- 最后回到学情管家首页或定格在知识图谱。

**旁白**

> 最后，我可以回到 78 个知识点、7 大板块的 AI 知识图谱，看清先修关系和自己在体系中的位置。智学中枢把“理解我、为我规划、可信生成、科学学习、持续评估”连成了一个闭环——让每个起点不同的学习者，都能拥有真正适合自己的 AI 学习路径。

## 三、录制前必须完成的预热

1. 后端与前端保持运行：前端 `http://localhost:3000/`，后端 `:8000`。
2. 使用 `learner_001` 登录一次，确认 Token 未过期。
3. 打开一次“神经网络基础”定制讲义，确保正文、Mermaid 图和引用都已渲染。
4. 真实执行一次“CNN 架构 / 初级”工作流，保留完成态用于回放。
5. 在即时辅导中提前发送脚本问题，确认苏格拉底回复与针对性资源清单已生成。
6. 在文档学习中提前问一次“核心概念/定理有哪些？”，确认答案和出处已出现。
7. 若展示视频，只使用已生成或预渲染的视频，禁止现场等待服务端渲染。
8. 正式录制前刷新页面，检查浏览器控制台无新增业务错误。

## 四、macOS 系统录制设置

### 推荐设置

- 浏览器窗口比例调整为 16:9，建议内容区约 1440×810 或直接全屏。
- 浏览器缩放保持 90%–100%，确保侧栏和主内容同时清晰可见。
- 关闭无关标签页、通知、聊天软件和自动更新弹窗。
- 隐藏书签栏；Dock 设为自动隐藏。
- 字体和主题保持浅色“鼠尾草”主题，画面更适合比赛演示。
- 麦克风使用耳机麦或独立麦，系统输入增益避免过高。

### 使用 macOS 自带录屏

1. 按 `Shift + Command + 5`。
2. 选择“录制所选部分”，框选浏览器内容区；如果要保留浏览器框架，则框选整个窗口。
3. 在“选项”中选择麦克风、保存位置，并关闭鼠标点击的多余视觉效果。
4. 点击录制前先把鼠标停在欢迎页空白处，口播后再开始移动。
5. 结束时按菜单栏停止按钮，或按 `Command + Control + Esc`。

### 更稳的成片方式

macOS 系统录制不能在一次录制中无痕跳过 DeepSeek 的等待时间。建议分成 3 段录制后拼接：

1. 欢迎页 → 画像 → 路径 → 资源；
2. 已预热的工作流真实片段；
3. 有序学习 → 文档学习 → 知识图谱 → 收尾。

转场只用 4–6 帧淡化或直接硬切，不使用花哨模板；旁白连续，成片观感仍像一次完整的系统录制。

## 五、录制时的操作习惯

- 鼠标移动要慢，点击后停 1–2 秒再说结论。
- 每屏只讲一个重点，不要一边快速滚动一边解释。
- 滚动幅度控制在一屏以内；需要跳到参考文献时可后期剪掉中间滚动。
- 不说“这个页面还有……”，要说“作为初学者，我现在需要……”。
- 工作流页面必须明确说“真实后端执行”，并让日志中的数值与回环出现在画面里。
- 不在成片中展示 API Key、终端日志、数据库文件或浏览器控制台。
