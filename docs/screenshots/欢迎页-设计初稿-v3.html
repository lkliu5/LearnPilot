创新点 02 · 真因材施教

不是"千人一面"，
而是"一人一路径"

我们用做题反推你的真实能力，而不是问"你觉得自己几分"。基础不同的人，看到的路径节点、顺序、甚至每一步的学习形式，都不一样。

  • 能力画像 → 决定学什么、什么顺序（薄弱前置）
  • 偏好画像 → 决定每步用什么形式（图像型给图解、案例型给例题）
  • 学习时间线 → 预计时长 / 周期 / 进度 / 节奏
