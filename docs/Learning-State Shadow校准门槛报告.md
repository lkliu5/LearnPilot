## 1. 已建立的观测口径

报告工具同时输出 7 天与 30 天窗口，并按以下维度分层：

- 来源：Quiz、Diagnostic、Feynman、Learning Step 的数量、覆盖和均分；
- 节点：每个知识点的 Event 数量；
- 活跃度：按窗口内用户 Event 数划分 low（1–2）、medium（3–9）、high（≥10）；
- 漂移：7 天相对 30 天的事件占比、mastery MAE 变化、阈值迁移率变化；
- 异常：30 天窗口内 duplicate、evidence_conflict 等审计数量与比率；
- 人工复核：Legacy 与 Shadow 跨掌握度阈值的样本，按绝对差异降序抽取最多 30 条。

## 2. 离线候选策略

线上 Shadow 默认参数保持 `ks-logodds-v1.1-shadow` 不变。离线回放增加以下候选：

1. session 封顶候选：Diagnostic 1.10、Feynman 1.40、Learning Step 每 UTC 日 0.45；
2. 冲突窗口：12h、24h（基线）、48h；
3. 冲突分差：0.30、0.40（基线）、0.50；
4. 冲突置信因子：0.65、0.75（基线）、0.85。

每个候选输出可比节点数、mastery MAE、阈值迁移率、被抑制权重和冲突次数。结果仅用于评审，不自动选择或上线参数。

## 3. Fail-closed 准入门槛

以下条件必须同时满足才可给出 GO：

| 条件 | 门槛 |
|---|---:|
| 30 天 Event | ≥ 200 |
| 30 天活跃用户 | ≥ 20 |
| 可比用户-节点 | ≥ 50 |
| 来源覆盖 | 四类来源全部覆盖 |
| mastery MAE | ≤ 0.15 |
| 阈值迁移率 | ≤ 20% |
| 冲突率 | ≤ 10% |
| 重复率 | ≤ 5% |
| 跨阈值人工复核 | 全部完成 |

缺样本、指标为 null、来源不全或存在待复核样本均判定 `BLOCK`。
