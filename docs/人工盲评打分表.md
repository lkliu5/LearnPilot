# 智学中枢 · 个性化讲义人工盲评打分表

> 用途：组织 5–10 名评审员，对系统生成的 18 份讲义（6 核心知识点 × 3 难度档）进行**盲评**，
> 以人工主观评分交叉验证自动化三量化指标（幻觉率 / 难度适配率 / 知识覆盖率）。
> 配套统计脚本：`backend/scripts/metrics/blind_eval_stats.py`。

## 一、盲评流程

1. **取样**：从资源页/接口导出 18 份讲义（`kpId × difficulty`），分别保存为纯文本，
   文件名用随机编号（如 `L01`…`L18`），**隐去**知识点名、难度档与"由 AI 生成"等任何提示，
   建立编号↔(知识点,难度) 的对照表，仅统计阶段使用。
2. **分发**：每位评审独立打分，互不讨论；建议打乱 18 份的呈现顺序，降低顺序效应。
3. **评分**：对每份讲义按下方 5 个维度各打 1–5 分（整数），可留一句简评。
4. **回收**：每位评审产出一份 CSV（见第四节模板），汇总后跑统计脚本。

## 二、评分维度与量表（5 维 · 各 1–5 分）

| 维度 | 含义 | 1 分（差） | 3 分（合格） | 5 分（优秀） |
|---|---|---|---|---|
| **准确性** accuracy | 内容是否正确、无事实错误/编造（对应"幻觉率") | 多处明显错误或臆造 | 个别小瑕疵，主干正确 | 严谨准确，无可见错误 |
| **完整性** completeness | 是否覆盖该知识点的核心概念（对应"知识覆盖率") | 遗漏多数核心概念 | 覆盖主要概念，略有缺失 | 核心概念齐全且成体系 |
| **难度适配** difficulty_fit | 语域/深度是否匹配标注难度（对应"难度适配率") | 与难度档明显错配 | 基本匹配 | 精准贴合该难度学习者 |
| **可读性** readability | 条理、结构、表达是否清晰流畅 | 杂乱难读 | 结构尚可 | 层次清晰、讲解流畅 |
| **实用性** usefulness | 对学习者掌握该知识点的帮助程度 | 帮助甚微 | 有一定帮助 | 很有启发、可直接学习 |

> 评分锚点示例（准确性）：把讲义中的关键论断与权威教材核对，出现"将 ReLU 说成把输入压缩到 (0,1)"
> 这类硬错误即应给低分；只有措辞不够精确但结论正确，给 3–4 分。

## 三、建议汇总指标

- **逐维度均分**（5 维各自的全体均值±标准差）；
- **总均分**（5 维等权平均）；
- **逐份讲义均分**（定位最弱讲义）；
- **逐难度档均分**（入门/初级/高级三档对比，交叉验证难度适配）；
- **评审一致性**：同一份讲义不同评审打分的离散度（标准差）与"组内差 ≤1 分"的比例。

## 四、CSV 模板（每位评审一份，UTF-8）

表头固定如下；`lecture_id` 用盲评随机编号，`rater` 为评审匿名编号：

```csv
rater,lecture_id,accuracy,completeness,difficulty_fit,readability,usefulness,comment
R1,L01,5,4,5,5,4,概念清晰
R1,L02,4,4,3,4,4,难度略浅
...
```

把所有评审的 CSV 放入同一目录（如 `backend/scripts/metrics/_blind/`），运行：

```bash
cd backend
python scripts/metrics/blind_eval_stats.py --dir scripts/metrics/_blind --out scripts/metrics/_out/blind_eval.json
```

脚本输出逐维度均分、总均分、逐份/逐难度均分与评审一致性，并写入 JSON 供报告引用。
（难度档对照：在某份 CSV 同目录放 `mapping.csv`，列 `lecture_id,difficulty` 即可启用逐难度统计；缺省跳过。）
