# LearnPilot 技术文档

## 文档优先级

发生契约或实现冲突时，按以下顺序确认：

1. [`后端接口文档.md`](后端接口文档.md)：接口路径、字段、枚举和错误码。
2. `frontend/src/` 中的 TypeScript 类型：前端实际消费契约。
3. [`开发需求说明文档.md`](开发需求说明文档.md)：业务目标、算法与总体架构。
