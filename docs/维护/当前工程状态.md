## 真实、半真实与保底边界

### 真实业务管线

- LangGraph 工作流和 Agent 节点调度。
- RAG 检索、重排、引用和逐句接地计算。
- 学习路径规则规划和数据持久化。
- JWT、SQLite 状态、任务状态机和资源 CRUD。
- SSE/WS 流式通道。
- 文档解析、专属文档检索和问答。
- Remotion/Edge TTS 可用时的视频与语音产物。

### 真流程、可替换推理

默认 Mock 模式通过 `LLMClient` 返回确定性结构化内容，但业务流程仍真实执行。配置可用模型和 Key 后切换真实推理；失败时部分能力会降级到确定性内容。

### 静态或半真实部分

- 岗位市场以离线快照/种子数据为主。
- 知识图谱主体节点和关系来自预置知识体系，掌握状态实时派生。
- 外部资源搜索存在离线种子与保底结果。
- Mock 模式的问答、视频分镜、图解等使用主题模板和规则。
- Provider 描述范围大于核心 `LLMClient` 原生实现范围；新增 Provider 前需逐能力验证。

对外表述必须区分以上三类，不得把离线快照或降级内容描述为实时生成。
