## 敏感与无关资料

毕业证书、学位证书、个人报名材料以及明显属于其他课程/项目的 DOCX，不应长期与源码仓库混放。建议由资料负责人：

1. 移至仓库外的受控资料目录。
2. 确认不在 Git 历史中。
3. 不交由自动化工具批量读取、打包或上传。

本轮仅做风险标注，不自动操作这些文件。
